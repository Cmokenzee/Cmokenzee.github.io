01

Co je VLAN a proč ji používat

VLAN (Virtual Local Area Network) je logické rozdělení fyzické sítě na izolované broadcast domény. Konfigurace softwarem na switchi – bez fyzického přepojování kabelů.

Bez VLAN

Všechna zařízení sdílí JEDEN broadcast domain. Broadcast z PC1 → všichni přijmou. Bezpečnostní riziko.

S VLAN

Switch rozdělí porty do logických skupin. Každá VLAN = samostatný broadcast domain. VLAN 10 nevidí broadcast z VLAN 20.

VLAN ID (VID)

Každá VLAN má unikátní ID (1–4094). VLAN 1 = default (všechny porty defaultně). Normal range: 1–1005. Extended: 1006–4094 (VTP transparent mode).

02

Výhody nasazení VLAN

Bezpečnost

Izolace citlivých dat (Finance, HR, Dev). Omezení broadcast storms. 802.1X autentizace.

Segmentace

Oddělení provozu podle oddělení/funkce. Menší broadcast domény = efektivnější bandwidth.

Flexibilita

Přesun PC z HR do Finance = jen změna VLAN na portu (ne kabel). Centralizovaná správa.

Škálovatelnost

Nové oddělení = nová VLAN + porty. Až 4094 VLANů. Spanning across switches (trunk).

QoS

Voice VLAN s vysokou prioritou (VoIP). CoS tagging (802.1p). Nižší latence pro kritické app.

Úspora nákladů

Jeden L3 switch místo mnoha routerů. Jeden fyzický switch = více logických sítí.

03

Typy portů

Access Port

Patří do jedné VLAN. Připojuje koncová zařízení (PC, servery, tiskárny). Switch nepřidává 802.1Q tag → koncová zařízení neví o VLANech (untagged).

switchport mode access
switchport access vlan 10
Trunk Port

Přenáší provoz více VLANů současně. Spojuje switche mezi sebou. Používá 802.1Q tagging – přidává 4 B VLAN tag do Ethernet rámce.

switchport mode trunk
switchport trunk allowed vlan 10,20,30
Native VLAN

Rámce přenášené na trunk portu bez tagu (untagged). Default: VLAN 1.

BEZPEČNOST: Native VLAN musí být stejná na obou koncích trunk! Změň z VLAN 1 na nepoužívanou (např. VLAN 99) – prevence VLAN hopping útoků.

switchport trunk native vlan 99
04

Speciální VLANy

Management VLAN

Vyhrazená pro vzdálenou správu zařízení (SSH, SNMP). Switch má IP v této VLAN. Best practice: nepoužívej VLAN 1, omez přístup ACL, používej SSH.

Voice VLAN

Speciální pro VoIP. IP telefon taguje voice (CoS 5), PC za telefonem posílá do data VLAN. QoS prioritizace → nízká latence.

Konfigurace Voice VLAN (Cisco)
switchport mode access
switchport access vlan 10 ! Data VLAN
switchport voice vlan 20 ! Voice VLAN
mls qos trust cos

Topologie: [Switch] ← → [IP Phone] ← → [PC]. Telefon taguje voice, PC netaguje.

Obsah 802.1Q tagu (4 B)
  • TPID (16 bit) – 0x8100 identifikuje 802.1Q tag
  • PCP (3 bit) – Priority Code Point (QoS, 0–7)
  • DEI (1 bit) – Drop Eligible Indicator
  • VID (12 bit) – VLAN ID (0–4095, efektivně 1–4094)

Max velikost rámce s tagem: 1522 B (baby giant) místo 1518 B.

Subnetting – základy

Subnetting = rozdělení větší IP sítě na menší podsítě. Každá podsíť = samostatný broadcast domain. IP adresa = síťová část + hostitelská část, hranici určuje subnet mask.

07

FLSM (Fixed-Length Subnet Mask)

Všechny podsítě mají stejnou velikost (stejný subnet mask). Jednoduché, ale neefektivní – plýtvání IP adresami.

Příklad: 192.168.1.0/24 → 4 podsítě

4 podsítě → 2² = 4 → 2 bity navíc → /24 + 2 = /26 (64 adres, 62 použitelných)

Nevýhoda: Subnet s 5 hosty dostane 62 adres → 57 nevyužito!

08

VLSM (Variable-Length Subnet Mask)

Každá podsíť může mít různou velikost. Efektivní – dimenzováno podle potřeby. Podporují: OSPF, EIGRP, BGP. RIPv1 nepodporuje (classful).

Postup VLSM
Seřaď podle velikosti (největší první) → přiděl nejbližší mocninu 2
Příklad: 192.168.1.0/24

Požadavky: A (100 hostů), B (50), C (25), D (10)

10

Topologie a Inter-VLAN routing

Hierarchický model (3 vrstvy)

Access L2 switche v každém oddělení. VLAN assignment na access portech. PoE pro IP telefony.
Distribution L3 switch – inter-VLAN routing (SVI pro každou VLAN). OSPF, redundance (HSRP/VRRP).
Core Firewall, WAN router k ISP. Internet gateway, NAT.

Inter-VLAN routing

L3 switch má SVI (Switched Virtual Interface) pro každou VLAN = default gateway pro zařízení v dané VLAN.

Příklad: Sales → Servers
1
PC v VLAN 20 (Sales) → packet na gateway 10.0.0.129
SVI VLAN 20 na L3 switchi
2
L3 switch routuje mezi VLANy
Změní MAC adresy (ne IP). Pošle packet do VLAN 50.
3
Server v VLAN 50 přijme packet
Propojení Access ↔ Distribution

Trunk port (802.1Q) mezi access L2 switchem a L3 switchem. Allowed VLANs: 10,20,30,40,50,60,99. Native VLAN: 99 (management).

Konfigurace (Cisco CLI)

L3 switch – VLANy a SVI (gateway)
! Vytvoření VLANů
vlan 10
name Management
vlan 20
name Sales
! ... opakuj pro všechny VLANy

! SVI = default gateway
interface vlan 10
ip address 10.0.1.1 255.255.255.240
no shutdown
interface vlan 20
ip address 10.0.0.129 255.255.255.192
no shutdown

! Zapni routing
ip routing
L3 switch – trunk port k access switchi
interface GigabitEthernet0/1
switchport trunk encapsulation dot1q
switchport mode trunk
switchport trunk allowed vlan 10,20,30,40,50,60,99
switchport trunk native vlan 99
Access switch – access porty a trunk
! Access porty pro Sales
interface range FastEthernet0/1 - 10
switchport mode access
switchport access vlan 20
spanning-tree portfast

! Trunk k L3 switchi
interface GigabitEthernet0/1
switchport mode trunk
switchport trunk native vlan 99
12

Bezpečnost

ACL (Access Control Lists)

Omez Guest VLAN → pouze internet, NE přístup k interním VLANům. Aplikuj na SVI interface.

Port Security

Omez počet MAC adres na portu (max 2). Violation: shutdown port. Prevence MAC flooding.

DHCP Snooping

Prevence rogue DHCP serverů. Trust na uplink portu, untrust na access portech.

Disable unused ports

Nepoužívané porty vypni (shutdown). Zabráníš připojení neautorizovaných zařízení.

Příklad ACL – izolace Guest VLAN
ip access-list extended GUEST_ACL
deny ip 10.0.0.192 0.0.0.31 10.0.0.0 0.0.3.255 ! deny internal
permit ip any any ! allow internet
interface vlan 60
ip access-group GUEST_ACL in
Port Security a DHCP Snooping
! Port Security
switchport port-security
switchport port-security maximum 2
switchport port-security violation shutdown

! DHCP Snooping
ip dhcp snooping
ip dhcp snooping vlan 10,20,30,40,60
! Na uplink portu:
ip dhcp snooping trust
13

Shrnutí klíčových bodů

Na zkoušku si zapamatuj
  • VLAN = logická izolace broadcast domén bez fyzického přepojování. ID 1–4094
  • Access port = 1 VLAN, untagged, koncová zařízení. Trunk port = více VLANů, 802.1Q tagged, spojení switchů
  • Native VLAN = untagged na trunk, default VLAN 1 → vždy změň na nepoužívanou! (bezpečnost)
  • 802.1Q tag = 4 B (TPID 0x8100 + PCP + DEI + VID). Max frame 1522 B (baby giant)
  • Management VLAN = SSH/SNMP správa. Voice VLAN = VoIP s QoS prioritou
  • FLSM = všechny podsítě stejné → jednoduché, plýtvání IP
  • VLSM = různé velikosti → efektivní. Postup: seřaď největší první → nejbližší mocnina 2
  • VLSM podporují: OSPF, EIGRP, BGP. RIPv1 nepodporuje
  • Vždy minus 2 adresy (network + broadcast): /25 = 126, /26 = 62, /27 = 30, /28 = 14
  • Návrh sítě: VLAN planning → VLSM subnetting → topologie (Access/Distribution/Core) → konfigurace → bezpečnost
  • L3 switch = inter-VLAN routing pomocí SVI (Switched Virtual Interface) = default gateway
  • Konfigurace: vytvoř VLANy → SVI (IP gateway) → ip routing → trunk (allowed VLANs) → access porty
  • Bezpečnost: ACL (izolace Guest), Port Security (max MAC), DHCP Snooping, disable unused ports, změň native VLAN
