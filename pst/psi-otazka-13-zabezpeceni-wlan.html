Tři pilíře zabezpečení

WLAN signál se šíří vzduchem → kdokoli v dosahu může zachytit. Cílem je chránit data před neoprávněným přístupem, odposloucháním a manipulací.

Autentifikace

KDO se připojuje? Ověření totožnosti (heslo, certifikát, 802.1X).

Šifrování

CO se přenáší? Ochrana obsahu dat v přenosu (AES, TKIP).

Autorizace

CO SMÍ přihlášený dělat? Kontrola přístupu (VLAN, bandwidth, pravidla).

02

MAC filtering a Hidden SSID

MAC Address Filtering

AP udržuje whitelist MAC adres → pouze zařízení na seznamu se připojí.

  • Slabost #1 – MAC spoofing: MAC adresa v plaintext (frame header). Útočník sniffuje → zjistí přípustné MAC → změní vlastní MAC
  • Slabost #2 – Správa: Manuální přidávání/odebírání → neškálovatelné

Závěr: SLABÁ ochrana. Chrání pouze před náhodným přístupem, NE před cíleným útočníkem. Pouze jako doplněk!

Hidden SSID (potlačení vysílání)

AP neoznamuje SSID v Beacon frames → síť se neobjevuje v seznamu.

  • Slabost #1 – Sniffing: SSID stále v Probe Request/Response a Association Request. Wireshark/Aircrack-ng → okamžitě odhalí
  • Slabost #2 – Probe leak: Klient periodicky vysílá Probe Request s hidden SSID

Závěr: SLABÁ ochrana. Útočník se sniffer okamžitě odhalí SSID. Pouze jako doplněk!

03

Typy autentifikace

Open Authentication

Žádná autentifikace. Kdokoli se připojí bez hesla. Žádné šifrování (pokud ne OWE/VPN). Příklad: veřejné Wi-Fi. Rizika: MITM, eavesdropping, rogue AP.

OWE (Opportunistic Wireless Encryption)

Šifrování BEZ hesla. Diffie-Hellman key exchange (ECDH) → AES-GCM. Per-session keys. Chrání data, ale NE přístup (kdokoli se připojí). = „Encrypted open."

05

WEP – broken! KOMPLETNĚ BROKEN

WEP (Wired Equivalent Privacy) – 1999

První pokus o zabezpečení WLAN. Šifrování: RC4 (stream cipher). Klíč: 40/104-bit, statický (nemění se!). IV: 24-bit (2²⁴ = 16M → brzy se opakuje). Integrita: CRC-32 (není kryptografická).

  • IV reuse: Po ~5000 paketech se IV opakuje → XOR attack → odhalení plaintextu
  • Weak IV: Některé IV odhalují klíčové byty (Fluhrer-Mantin-Shamir attack)
  • CRC manipulace: CRC-32 ≠ autentizace → útočník může modifikovat pakety
  • Aircrack-ng: Cracking za minuty (10K–100K paketů)

NIKDY NEPOUŽÍVAT!

06

WPA – TKIP DEPRECATED

WPA (Wi-Fi Protected Access) – 2003

Rychlá záplata pro WEP (HW kompatibilní). Šifrování: TKIP (RC4 s dynamickými klíči).

  • Per-packet key mixing – každý paket jiný klíč (ne statický!)
  • 48-bit IV (vs WEP 24-bit) → 2⁴⁸ paketů
  • MIC (Michael) – Message Integrity Code → detekce manipulace
  • Anti-replay – sekvenční číslo → detekce replay attacks

Lepší než WEP, ale stále RC4 → known attacks (Beck-Tews). Přejít na WPA2!

07

WPA2 – AES-CCMP AKTUÁLNÍ STANDARD

WPA2 (802.11i) – 2004

Kompletní přepis zabezpečení. Povinné pro Wi-Fi certifikaci od 2006. Nejpoužívanější dnes.

  • AES – silný symetrický cipher (128-bit block cipher)
  • CCMP – AES + CTR mode (šifrování) + CBC-MAC (integrita)
  • Dynamické klíče – per-session, generované při 4-way handshake
4-Way Handshake (WPA2-Personal)
1
AP pošle ANonce (random)
2
Klient generuje SNonce + odvodí PTK
PTK z: PSK + ANonce + SNonce + MAC adresy → pošle AP
3
AP ověří PTK → pošle GTK (Group Temporal Key) + MIC
4
Klient potvrdí → šifrovaná komunikace
PTK = unicast, GTK = multicast/broadcast
Slabosti WPA2
  • PSK cracking: Zachytit 4-way handshake → offline dictionary/brute-force na heslo
  • PMKID attack: Stačí jeden EAPOL frame od AP → offline crack (nepotřebuje handshake!)
  • KRACK (2017): Key reinstallation attack → přinutí klient reinstalovat session key → replay, decrypt
08

WPA3 – SAE, GCMP NEJBEZPEČNĚJŠÍ

WPA3 – 2018

Nejnovější standard. Řeší slabosti WPA2. Wi-Fi 6 vyžaduje WPA3.

Šifrování: AES-GCMP (Galois Counter Mode). AES-256 v Enterprise, AES-128 v Personal.

SAE (Simultaneous Auth of Equals)

Nahrazuje PSK v Personal. Dragonfly key exchange (jako DH). Offline cracking NEMOŽNÝ! I se slabým heslem bezpečný.

Forward Secrecy

Kompromitace hesla neodhalí dříve zachytený provoz. Per-session keys.

MFP (Management Frame Protection)

Povinné. Chrání management frames (deauth, disassoc). Řeší deauthentication attacks.

192-bit Suite (Enterprise)

AES-256 + SHA-384 + ECDHE. Vyšší zabezpečení pro kritické prostředí.

10

Šifrování: PSK, TKIP, AES, CCMP

PSK (Pre-Shared Key)

Sdílené heslo → ne šifrovací klíč samotný, ale základ pro derivaci klíčů:

PSK (heslo) → PMK (Pairwise Master Key) → 4-way handshake → PTK (session key) → šifrování

Délka: 8–63 znaků. Doporučení: 12+ znaků, mix letters+numbers+symbols. Nejlepší: 20+ random.

TKIP DEPRECATED

RC4 + dynamic keys + 48-bit IV + MIC (Michael). WPA. Stále RC4 → known attacks.

AES

Symetrický block cipher 128/256-bit. NIST standard. Gold standard. Žádný praktický attack. WPA2/3.

CCMP vs GCMP

CCMP (WPA2) = AES + CTR mode (šifrování) + CBC-MAC (integrita). AEAD.

GCMP (WPA3) = AES-GCM (Galois Counter Mode). Silnější, efektivnější, HW-accelerated.

11

802.1X, EAP, RADIUS, AAA

AAA Framework
  • Authentication (WHO?) – ověření totožnosti (username/password, certifikát)
  • Authorization (WHAT?) – co smí user dělat (VLAN, bandwidth, access rights)
  • Accounting (WHEN/HOW MUCH?) – logging přístupu (kdo, kdy, jak dlouho, kolik dat)

802.1X – Port-Based Access Control

Framework pro autentizaci přístupu na PORT úrovni. Tři role:

Supplicant
Klient (laptop, telefon). Posílá credentials.
→
Authenticator
AP / Switch. Přeposílá na server. Neověřuje sám!
→
Auth Server
RADIUS. Skutečně ověřuje a rozhoduje.

Port před autentizací = UNAUTHORIZED (blokovaný). Po úspěchu = AUTHORIZED → provoz povolen.

RADIUS Server

RADIUS (Remote Authentication Dial-In User Service)
  • Protocol: UDP port 1812 (authentication), 1813 (accounting)
  • Shared secret mezi RADIUS a Authenticator
  • Access-Request: Authenticator → RADIUS (credentials)
  • Access-Accept: RADIUS → Auth (povolen + atributy: VLAN, timeout)
  • Access-Reject: RADIUS → Auth (odmítnut)
  • Access-Challenge: RADIUS → Auth (potřeba víc info, MFA)
RADIUS vs TACACS+
  • RADIUS: UDP, combined auth+authz, standard pro WLAN/LAN access
  • TACACS+: TCP, separates auth/authz/accounting, Cisco preferred pro device management (CLI)

14

Shrnutí klíčových bodů

Na zkoušku si zapamatuj

SLABÉ OCHRANY

  • MAC filtering + Hidden SSID = slabé (MAC spoofing, sniffing). Pouze doplněk, ne hlavní ochrana!

AUTENTIFIKACE

  • Open: žádná. OWE: „encrypted open" (DH, bez hesla, chrání data ne přístup)
  • Personal = PSK (jedno heslo). Enterprise = 802.1X + EAP + RADIUS (per-user, centrální)

PROTOKOLY

  • WEP RC4, 24-bit IV, CRC-32. BROKEN, nikdy nepoužívat!
  • WPA TKIP (RC4 + dynamic keys + MIC). Deprecated
  • WPA2 AES-CCMP, 128-bit. Aktuální standard. Slabost: PSK cracking, PMKID, KRACK
  • WPA3 AES-GCMP, SAE (ne PSK!), forward secrecy, MFP povinné. Nejbezpečnější

ŠIFROVÁNÍ

  • TKIP = RC4 + dynamic keys (deprecated). AES = gold standard (128/256-bit)
  • CCMP = AES-CTR + CBC-MAC (WPA2). GCMP = AES-GCM (WPA3, silnější)

802.1X + EAP + RADIUS

  • 802.1X: Supplicant → Authenticator → Auth Server. Port: UNAUTHORIZED → AUTHORIZED
  • EAP: MD5 (broken), TLS (nejbezpečnější, mutual cert), TTLS (nejpoužívanější, server cert + password), PEAP (Windows)
  • RADIUS: UDP 1812/1813. Access-Request / Accept / Reject / Challenge
  • AAA: Authentication (KDO) + Authorization (CO SMÍ) + Accounting (KDY/KOLIK)
