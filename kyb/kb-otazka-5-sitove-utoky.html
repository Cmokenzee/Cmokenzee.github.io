01

Man-in-the-Middle (MITM)

Útočník se tajně umístí mezi dvě komunikující strany a odposlouchává nebo modifikuje komunikaci. Oběti si myslí, že spolu mluví přímo.

Alice
→
Eve
útočník
→
Bob
Alice si myslí, že mluví přímo s Bobem. Eve čte/mění vše.
Typy MITM útoků
  • ARP Spoofing: Falešné ARP zprávy → přesměrování provozu na útočníka
  • DNS Spoofing: Změněné DNS odpovědi → falešná stránka
  • SSL Stripping: Downgrade HTTPS → HTTP (nešifrované!)
  • Wi-Fi Eavesdropping: Odposlech na veřejné Wi-Fi
  • Session Hijacking: Krádež session cookie

Lenovo Superfish (2015): Předinstalovaný adware prováděl MITM na VŠECHNY HTTPS spojení. Vložil vlastní certifikát.

Ochrana

HTTPS všude (zelený zámek). VPN na veřejné Wi-Fi. Certificate pinning. HSTS (vynucuje HTTPS). Nepoužívat veřejné Wi-Fi pro citlivé transakce.

02

Man-in-the-Mobile (MitMo)

📱MitMoMOBILNÍ

MITM varianta pro mobily. Trojan na mobilu zachytává SMS 2FA kódy. Zeus-in-the-Mobile (ZitMo) – zachytil bankovní SMS s potvrzovacím kódem a přeposlal útočníkovi.

Ochrana: Oficiální store only. Kontrolovat oprávnění (proč kalkulačka chce SMS?). Authenticator app místo SMS pro 2FA. Aktualizace OS.

Slavné DDoS útoky
  • Mirai (2016): 600K IoT botů, 1.2 Tbps → vyřadilo Twitter, Netflix, Reddit, Spotify
  • GitHub (2018): 1.35 Tbps, Memcached amplification
  • AWS (2020): 2.3 Tbps – rekord
  • Estonia (2007): Cyberwar – DDoS na vládu, banky, média
DoS typy + Amplification

Typy: SYN Flood (TCP handshake abuse), Ping of Death, HTTP Flood, Teardrop.

Amplification: Útočník pošle malý požadavek (10 KB) se spoofovanou IP oběti → server odpoví 1000 KB → oběť dostane 100× větší provoz. DNS/NTP/Memcached amplification.

Ochrana

CDN (Cloudflare, Akamai). Rate limiting. Anycast network. Blackhole routing. DDoS mitigation služby (AWS Shield). Redundance + škálovatelnost.

04

Sniffing a Port Scanning

Sniffing (Packet Sniffing) 👃

Zachytávání síťových paketů. NIC v „promiscuous mode" → vidí VŠE na síti. Nástroje: Wireshark, tcpdump. Zachytí: hesla (HTTP!), cookies, emaily, FTP credentials. Passive (hub) vs Active (switch + ARP spoof).
Ochrana: šifrování (HTTPS, SSH, VPN), switch místo hub, ARP inspection, port security.

Port Scanning 🔍

Reconnaissance – skenování otevřených portů a služeb. Nástroj: Nmap. nmap -sV 192.168.1.100 → zjistí porty (80=Apache, 22=SSH, 3306=MySQL). Není útok sám o sobě, ale příprava.
Typy: TCP Connect (hlučný), SYN scan (stealth), UDP, FIN/XMAS.
Ochrana: firewall, IDS/IPS, port knocking, disable unused services.

05

Spoofing (všechny typy)

Spoofing = falšování identity v síti. Útočník předstírá, že je někdo/něco jiného.

IP SpoofingFalešná source IP. Obcházení firewallu, DDoS.
ARP SpoofingFalešné ARP → provoz přes útočníka → MITM.
DNS SpoofingFalešné DNS → phishing stránka. Cache poisoning.
Email SpoofingFalešný „From:" – SMTP neověřuje! Phishing, BEC.
Caller IDFalešné číslo volajícího. Vishing útoky.
MAC SpoofingZměna MAC. Obcházení MAC filtering.
Ochrana proti spoofingu

Packet filtering (firewall). Email auth: SPF, DKIM, DMARC. DNSSEC (digitální podpisy DNS). ARP inspection na switchích. Port security. Encryption eliminuje dopad.

06

SEO Poisoning, Browser Hijacker

SEO Poisoning 🔍💀

Manipulace výsledků vyhledávačů (Google) → škodlivé weby na vysokém rankingu. Keyword stuffing, link farming, cloaking. Hledáš „download adobe reader" → první výsledek = malware.
Ochrana: Stahovat z oficiálních webů. Kontrolovat URL. Google Safe Browsing. Antivirus s web protection.

Browser Hijacker 🌐

Modifikuje nastavení prohlížeče bez svolení. Změní homepage, vyhledávač, přidá toolbary, pop-upy. Přes bundled software nebo fake updates.
Známé: Conduit, Ask Toolbar, Babylon.
Odstranění: Control Panel, reset browser, AdwCleaner.

07

Grayware

⚪GraywareŠEDÁ ZÓNA

Ani malware, ani legitimní. Nechtěný, otravný, ale ne nutně destruktivní. Adware, tracking cookies, PUP (Potentially Unwanted Programs), toolbary.

Problém: Zpomaluje PC, narušuje soukromí, těžko se odstraňuje. Ochrana: Pozorně číst instalaci, oficiální zdroje, AdwCleaner.

08

Rogue AP / Evil Twin

Neautorizovaný wireless AP připojený k síti – záměrně (útočník) nebo neúmyslně (zaměstnanec).

Evil Twin 👿📶

Falešný AP se stejným SSID jako legitimní síť. Telefon se automaticky připojí (silnější signál). Útočník vidí veškerý provoz → MITM. Příklad: „Airport_Free_WiFi" na letišti.

Zaměstnanecký Rogue AP

Zaměstnanec si přinese vlastní router → neúmyslná bezpečnostní díra. AP obchází firemní firewall a security.

Detekce a ochrana
  • WIDS (Wireless IDS) – detekuje neznámé AP
  • 802.1X – network access control
  • VPN – i na rogue AP útočník nevidí šifrovaný provoz
  • NAC – kontrola autorizace zařízení
  • Neautomaticky se připojovat k Wi-Fi. Ověřovat SSID u personálu
09

Komplexní ochrana – Defense in Depth

Vícevrstvá obrana – když jedna vrstva selže, další zastaví útok.

Vrstva 1: PERIMETER – Firewall, IDS/IPS
Vrstva 2: NETWORK – Segmentace (VLAN), VPN, NAC
Vrstva 3: HOST – Antivirus, HIDS, patching
Vrstva 4: APPLICATION – WAF, input validation
Vrstva 5: DATA – Encryption, zálohy
10

Shrnutí klíčových bodů

Na zkoušku si zapamatuj

ÚTOKY NA KOMUNIKACI

  • MITM: Útočník mezi oběťmi. ARP/DNS spoofing, SSL stripping, session hijack. Ochrana: HTTPS, VPN, HSTS
  • MitMo: Mobilní MITM – zachytává SMS 2FA kódy. Ochrana: authenticator app místo SMS
  • Sniffing: Zachytávání paketů (Wireshark). Promiscuous mode. Ochrana: šifrování

DOSTUPNOST

  • DoS: 1 zdroj → zahlcení serveru. DDoS: botnet (tisíce zdrojů) → velmi těžké blokovat
  • Mirai (2016): 1.2 Tbps, 600K IoT botů. Amplification: 100× zesílení
  • Ochrana: CDN (Cloudflare), rate limiting, anycast, redundance

SPOOFING A PRŮZKUM

  • Spoofing: IP (DDoS), ARP (MITM), DNS (phishing), Email (BEC – SMTP neověřuje!), MAC, Caller ID
  • Port Scanning: Nmap, SYN scan (stealth). Příprava na útok, ne útok samotný
  • Ochrana: SPF/DKIM/DMARC (email), DNSSEC, ARP inspection, port security

OSTATNÍ + OBRANA

  • SEO Poisoning: Falešné weby na vysokém Google rankingu. Browser Hijacker: Změní homepage/vyhledávač
  • Grayware: Šedá zóna – otravné ale ne destruktivní (PUP, adware, toolbary)
  • Rogue AP / Evil Twin: Falešný AP se stejným SSID → MITM. Ochrana: WIDS, 802.1X, VPN
  • Defense in Depth: 5 vrstev (Perimeter → Network → Host → Application → Data)
