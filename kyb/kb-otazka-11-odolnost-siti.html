Firewall – evoluce generací

Firewall = „brána" mezi důvěryhodnou a nedůvěryhodnou sítí. Monitoruje a kontroluje traffic na základě pravidel.

1.Packet FilterSTATELESS. IP, porty, protokoly. Rychlý ale bez kontextu.
2.StatefulSleduje stav spojení (state table). Return traffic auto-povoleno.
3.Application LayerDPI, L7 inspekce. Proxy. Vidí HTTP/FTP obsah. Pomalý.
NGNGFWVše v jednom: Stateful + DPI + IPS + App control + SSL inspect.
02

Next-Generation Firewall (NGFW)

NGFW = standard pro enterprise
  • Stateful inspection + Deep Packet Inspection (DPI)
  • Integrovaný IPS
  • Application Awareness – identifikuje apps podle behavior (ne jen portu). Skype na port 443? Detekuje!
  • SSL/TLS Inspection – dekóduje šifrovaný traffic
  • URL Filtering – blokuje malicious/unwanted weby
  • Threat Intelligence – real-time updates. Sandboxing – testování suspicious files

Vendors: Palo Alto, Cisco Firepower, Fortinet FortiGate, Check Point.

FW Best Practices

Default Deny (vše zakázáno). Least Privilege (jen nutný traffic). Pravidla odshora dolů (pořadí!). Quarterly audit pravidel. Dokumentace (business justification). Loguj vše (allow i deny).

03

IDS (Intrusion Detection System)

IDS = ALARM 🚨 (pasivní, jen detekuje a alertuje)

Připojeno na SPAN/mirror port (out-of-band). Kopie trafficu → analýza proti signatures/rules → match = ALERT. NEBLOKUJE! Zero performance impact.

NIDS (Network-based)

Monitoruje celou síť. Strategické body (perimeter, mezi segmenty). Příklady: Snort, Suricata, Zeek.

HIDS (Host-based)

Běží na individuálním hostu. File integrity, system calls, logs. Příklady: OSSEC, Tripwire.

04

IPS (Intrusion Prevention System)

IPS = POLICIE 🛑 (aktivní, detekuje a BLOKUJE)

Zapojený INLINE (v cestě trafficu). Všechen traffic MUSÍ projít přes IPS. Malicious → DROP/BLOCK. Legitimate → PASS.

Riziko: SPOF (IPS spadne = síť down). False positives = blokovaný legitimní traffic. Performance impact.

IDS vs IPS – klíčový rozdíl

🚨 IDS
  • Out-of-band (mirror port)
  • PASIVNÍ – jen monitoruje
  • Alertuje security team
  • Zero performance impact
vs
🛑 IPS
  • Inline (in the path)
  • AKTIVNÍ – blokuje
  • Automatická prevence
  • Může být SPOF

IPS Actions: Drop/Block packet, Reset connection (TCP RST), Block source IP, Alert + Pass (monitoring mode).

05

Detekční metody

Signature-Based Hledá známé vzory útoků (signatures). Jako antivirus pro síť. + Nízká false positive. − Nedetekuje zero-day!
Anomaly-Based Vytvoří baseline normálu. Odchylka = anomálie = alert. + Detekuje zero-day. − Vysoká false positive!
Behavior-Based Analyzuje chování entit (users, devices). Machine learning. Detekuje sophisticated + insider threats.
06

Behavior-Based Security

Analýza CHOVÁNÍ místo signatures. ML/AI identifikuje anomální chování. Detekuje zero-day, insider threats, APT.

Jak to funguje – 3 fáze
1
Baseline Creation (Learning Phase) – systém pozoruje týdny/měsíce. Učí se „normální": Jan se přihlašuje 8–17 z Prahy, přistupuje k CRM, email. Web server posílá 5 GB/den.
2
Continuous Monitoring – neustálé porovnávání s baseline.
3
Anomaly Detection – odchylka = alert/block. Jan se přihlásil ve 3:00 z Ruska? 100 GB outbound místo 5 GB?
UEBA (User and Entity Behavior Analytics)

Specializovaný behavior systém. Analyzuje: login patterns, data access, lateral movement, privilege escalation. Přiřazuje risk score – čím více anomálií, tím vyšší. High score → investigation/auto-response.

Use cases: Insider threat, compromised accounts, APT detection, data exfiltration.

07

NetFlow

NetFlow (Cisco) = sběr IP traffic statistik. KDO komunikuje s KÝM, KDY, KOLIK dat. „Call detail records" pro síť. Neexportuje payload – jen metadata!

Flow Record:
Src IP: 10.0.0.5 → Dst IP: 93.184.216.34
Src Port: 54321 → Dst Port: 443 (HTTPS)
Protocol: TCP | Packets: 1523 | Bytes: 2,456,789 | Duration: 3600s
Flow = 7 klíčů

Source IP, Destination IP, Source Port, Destination Port, L3 Protocol (TCP/UDP), Type of Service, Input Interface. Verze: v5 (legacy), v9 (template), IPFIX (IETF standard). Alternativy: sFlow, jFlow.

Security Use Cases

Anomaly: DDoS spike, data exfiltration. Malware: Botnet beaconing, port scanning, lateral movement. Forensics: Timeline, tracking, scope. Policy: Torrenty, unauthorized services.

Výhody / Nevýhody

+ Lightweight, comprehensive visibility, long-term storage, metadata i u šifrovaného trafficu. − Žádný payload (nevidíš obsah), velká storage, vyžaduje analýzu. Nástroje: Cisco Stealthwatch, SolarWinds NTA, nfdump.

08

Segmentace, NAC, Honeypot

Network Segmentation

VLAN: HR VLAN 10, Finance VLAN 20, Guest VLAN 30. DMZ: Izolovaný segment pro public services (Internet ← FW1 → DMZ ← FW2 → Internal). Micro-segmentation: SDN, datacenter/cloud.

NAC (Network Access Control)

Kontrola KDO/CO se připojí. 802.1X auth + posture check (AV aktuální? Patche? Firewall?). Compliant → full access. Non-compliant → quarantine VLAN. Use: BYOD, guests, IoT.

Honeypot 🍯

Decoy systém = past. Vypadá jako production, ale žádný legitimní traffic → jakýkoliv traffic = útočník! Early warning, distraction, research.

09

Shrnutí klíčových bodů

Na zkoušku si zapamatuj

FIREWALL EVOLUCE

  • 1. gen: Packet Filter (stateless). 2. gen: Stateful (state table). 3. gen: Application Layer (DPI, proxy)
  • NGFW: Stateful + DPI + IPS + App control + SSL inspect + URL filter + sandboxing. Enterprise standard!
  • Best practices: Default Deny, Least Privilege, pravidla odshora dolů, quarterly audit, loguj vše

IDS vs IPS

  • IDS = ALARM 🚨: Out-of-band, pasivní, jen alertuje. NIDS (síť: Snort, Suricata) / HIDS (host: OSSEC)
  • IPS = POLICIE 🛑: Inline, aktivní, blokuje. Drop/Reset/Block. Riziko: SPOF, false positives = blocked legit traffic

DETEKCE

  • Signature-based: Známé vzory. + Nízká false positive. − Nedetekuje zero-day
  • Anomaly-based: Baseline → odchylka = alert. + Detekuje zero-day. − Vysoká false positive
  • Behavior-based (UEBA): ML analýza chování. Risk scoring. Detekuje insider threats, APT, compromised accounts

NETFLOW + DALŠÍ

  • NetFlow: Metadata trafficu (ne payload!). 7 klíčů (src/dst IP+port, protocol, ToS, interface). IPFIX = standard. Security: anomaly, malware, forensics
  • Segmentace: VLAN, DMZ (Internet←FW→DMZ←FW→Internal), micro-segmentation
  • NAC: 802.1X + posture check. Compliant → access. Non-compliant → quarantine VLAN
  • Honeypot: Decoy = past. Jakýkoliv traffic = útočník. Early warning + research
  • Defense in Depth: Firewall + IPS + Segmentation + Monitoring + Endpoint. Zero Trust: Nikdy nedůvěřuj, vždy ověřuj!
