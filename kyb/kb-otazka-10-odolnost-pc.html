01

Co je hardening

Hardening = snížení útočné plochy (attack surface). Odstraňujeme zbytečné služby, zavíráme porty, konfigurujeme bezpečnostní nastavení. Default konfigurace je VŽDY nezabezpečená!

5 principů hardeningu
  • Least Privilege – minimální nutná práva
  • Minimize Attack Surface – vypnout co není potřeba
  • Defense in Depth – více vrstev ochrany
  • Secure by Default – bezpečná výchozí konfigurace
  • Fail Securely – při chybě systém zůstane zabezpečený
02

Patch Management

60 % breaches = ZNÁMÉ zranitelnosti s dostupným patchem!

WannaCry (2017): Patch dostupný 2 měsíce předem. Equifax (2017): Apache Struts patch 2 měsíce starý. Patching je #1 obrana.

Patch Management proces
  • 1. Monitoring – sledování security bulletins (Microsoft, vendors)
  • 2. Assessment – vyhodnocení kritičnosti (CVSS score)
  • 3. Testing – test na non-production prostředí
  • 4. Deployment – nasazení (staged rollout)
  • 5. Verification – ověření že patch je nainstalovaný

Priority: Critical (CVSS 9-10) → 24-48 h. High (7-8.9) → 1 týden. Medium/Low → měsíční cyklus. Nástroje: WSUS, SCCM, Ansible, Puppet.

03

Minimalizace služeb a softwaru

„If you don't need it, remove it." Každá služba = potenciální zranitelnost. Méně SW = menší attack surface.

Vypnout služby

Windows: Print Spooler, Remote Desktop, Telnet. Linux: FTP, Telnet, rsh, NFS. Web: directory listing, WebDAV.

Odstranit SW

Bloatware, trial SW, Adobe Flash (EOL). Dev tools na production serverech. Inventář SW pro detekci shadow IT.

Default accounts

Přejmenuj/odstraň default admin. Vypni Guest. Změň default hesla! (router admin/admin).

04

Správa účtů a přístupů

Principle of Least Privilege
  • Běžná práce = Standard User. Admin úkony = separate admin account (UAC/sudo)
  • NIKDY nepracuj v admin účtu pro daily tasks!
  • MFA VŽDY pro: admin účty, remote access (VPN, RDP), privileged ops
  • Password Policy: 12+ znaků, komplexita, lockout po X pokusech
  • Audit: Quarterly review, odstranění neaktivních (90+ dní), immediate disable při offboardingu
05

Firewall a síťové zabezpečení

Host-based Firewall = VŽDY zapnutý!
  • Default Deny: Vše zakázáno, explicitně povoluj jen nutný traffic
  • Blokuj: Inbound connections (kromě povolených), nepotřebné porty, legacy protocols (Telnet 23, FTP 21, SMBv1)
  • Scan sám sebe: nmap -sS -sV localhost → zjisti co běží
  • Network Segmentation: VLANs – workstations, servery, dev, guest Wi-Fi izolovaná
  • Disable unused NICs: Server má Wi-Fi ale používá Ethernet? → vypni Wi-Fi
06

Šifrování

Data at Rest (FDE)

Full Disk Encryption: BitLocker (Win), FileVault (macOS), LUKS (Linux), VeraCrypt. Laptop ukraden → data nečitelná.

Data in Transit

HTTPS místo HTTP, SSH místo Telnet, SFTP místo FTP, IMAPS/SMTPS. VPN pro remote access = povinné na veřejné Wi-Fi.

07

Antivirus a EDR

Moderní Endpoint Protection

Moderní AV ≠ jen signatures. Kombinuje: Signatures + Heuristics + Behavioral analysis + ML + Cloud reputation.

  • Real-time scanning, auto updates, scheduled full scans
  • Ransomware protection, web protection, email scanning
  • EDR (CrowdStrike, Defender for Endpoint, SentinelOne) = continuous monitoring + threat hunting + incident response
  • Application Whitelisting (AppLocker) = jen schválené apps. Vše ostatní blokováno

AV není silver bullet! Je jen jedna vrstva. Nechrání před zero-days, social engineering nebo targeted attacks.

08

Logging a monitoring

Co logovat

Auth events (login success/fail). Privileged ops (sudo, admin elevation). File access (citlivé soubory). System changes (config). Network connections.

Windows: Security Log, System Log, Application Log. Linux: /var/log/auth.log, /var/log/syslog.

Centralized logging → SIEM (Splunk, ELK, QRadar). Logy read-only, retention min 90 dní. Útočník často maže logy → proto centralizované!

09

Fyzické zabezpečení

BIOS/UEFI Password

Prevence bootování z USB/CD, změn boot order. Secure Boot = bootuje jen signed OS (anti-bootkit/rootkit).

Screen Lock + USB

Auto-lock po N min nečinnosti. Win+L při odchodu. Disable USB ports nebo whitelist (anti rubber ducky, data exfiltration).

Cable Locks

Kensington lock na laptopy. Fyzická prevence krádeže.

10

Server hardening

Základy
  • Minimální instalace: Windows Server Core (bez GUI), Linux minimal. GUI = větší attack surface
  • 1 server = 1 role. Web ≠ DB ≠ File server. Separace = izolace kompromitace
  • Dedikované service accounts s minimálními právy. NIKDY root/SYSTEM pokud není nutné
  • Remote: SSH (ne Telnet), key-based auth, disable root login, NLA pro RDP, jen přes VPN
Web Server (Apache/Nginx/IIS)
  • Disable directory listing, hide version numbers (ServerTokens Prod)
  • Disable unnecessary modules, proper file permissions
  • HTTPS only (redirect HTTP → HTTPS), security headers (CSP, HSTS, X-Frame-Options)
Database Server (MySQL/PostgreSQL/SQL Server)
  • Change default ports (MySQL 3306, PostgreSQL 5432). Disable remote root login
  • Least privilege app accounts. TDE (Transparent Data Encryption). SSL/TLS connections
  • MySQL: mysql_secure_installation, remove test DBs, bind to localhost
Virtualizace a kontejnery (Docker)
  • Hypervisor patched (ESXi, Hyper-V). Isolate management network
  • Docker: official/verified images, scan (Trivy, Clair), run as non-root, limit resources, secrets management, read-only FS
11

Hardening frameworks a automatizace

CIS Benchmarks

Center for Internet Security. Community-driven, free. Detailní checklist pro každou platformu (Win, Linux, Cloud, DB). Level 1 (basic) a Level 2 (defense in depth). CIS-CAT = automatický scanner.

STIG

DISA (US DoD). Velmi přísné, vojenský standard. Detailnější než CIS.

NIST

Cybersecurity Framework: Identify → Protect → Detect → Respond → Recover. NIST 800-53 = security controls.

Automatizace hardeningu
  • Ansible (agentless, YAML) – deploy hardening configs na 100 serverů
  • Puppet / Chef (agent-based) – desired state, continuous enforcement
  • Group Policy (GPO) – centrální Windows správa v AD
  • Golden Images – pre-hardened VM/container template. Deploy → už je hardened

Testování: Vulnerability scanning (Nessus, OpenVAS) měsíčně. Pen-testing ročně. Configuration audit quarterly.

Shrnutí klíčových bodů

Na zkoušku si zapamatuj

8 OBLASTÍ HARDENINGU

  • 🩹 Patching: #1 obrana. 60 % breaches = known vulns. Critical CVSS 9+ → 24–48 h. WSUS, Ansible
  • ✂️ Minimalizace: „If you don't need it, remove it." Služby, SW, default accounts
  • 👤 Účty: Least privilege, standard user pro daily, MFA pro admin/remote, quarterly audit
  • 🔥 Firewall: Host-based VŽDY ON. Default Deny. Zavřít nepoužívané porty. VLAN segmentace
  • 🔒 Šifrování: FDE (BitLocker/FileVault/LUKS). HTTPS/SSH/SFTP. VPN pro remote
  • 🛡️ AV/EDR: Signatures + behavioral + ML. EDR (CrowdStrike). AppLocker whitelisting. Není silver bullet!
  • 📋 Logging: Auth, privileged ops, file access → SIEM (Splunk). Read-only, centralizované, 90+ dní
  • 🏢 Fyzické: BIOS password, Secure Boot, screen lock (Win+L), USB control, cable locks

SERVER HARDENING

  • Minimal install (Server Core, no GUI). 1 server = 1 role. Dedikované service accounts
  • Web: No directory listing, hide versions, HTTPS only, security headers
  • DB: Change default ports, no remote root, TDE encryption, least privilege
  • Docker: Official images, scan (Trivy), non-root, limit resources, secrets management

FRAMEWORKS & AUTOMATIZACE

  • CIS Benchmarks (community, free, Level 1/2). STIG (vojenské). NIST (federal, Identify→Protect→Detect→Respond→Recover)
  • Automatizace: Ansible/Puppet/Chef, Group Policy (GPO), Golden Images
  • Lifecycle: Baseline → Deploy → Monitor → Maintain → Audit. Kontinuální proces!
  • 80 % útoků = KNOWN vulnerabilities. Patching + hardening to řeší!
