01

IR Lifecycle (NIST SP 800-61)

Strukturovaný přístup k detekci, analýze, containmentu a obnově. Průměrná detekce breache: 207 dní. Průměrná cena: $4.45M. S IRP ušetříš ~$2M.

02

Preparation (Příprava)

"Failing to prepare is preparing to fail"
  • IRT (Incident Response Team): Incident Commander, Security Analyst, Forensics, Legal, PR, Management. 24/7 on-call
  • IRP (Incident Response Plan): Procedury, escalation, kontakty, komunikační šablony, playbooks
  • Nástroje: SIEM, forensics (EnCase, Volatility), Wireshark, malware sandbox, backup/restore
  • Training: Tabletop exercises, full-scale drills, purple team
  • Prevence: Hardening, patching, security awareness, Defense in Depth
03

Detection & Analysis

Zdroje alertů + IoC

Zdroje: SIEM, IDS/IPS, AV/EDR, DLP, user reports, third-party notification.

IoC (Indicators of Compromise): Unusual network traffic, unknown processes, suspicious file changes, unauthorized logins, file hash = known malware.

Severity: P1 Critical (production down, data breach) → P2 High → P3 Medium → P4 Low.

Analýza: Scope (které systémy?), Root Cause (jak se dostal dovnitř?), Timeline. VŽDY dokumentuj vše! Screenshots, logy, chain of custody.

04

Containment, Eradication, Recovery

🛑 Containment (Izolace)

Short-term: Network isolation, disable accounts, block IPs, shutdown (last resort). Long-term: Přesun na clean systémy, temp patches, enhanced monitoring. „Stop the bleeding!"

🗑️ Eradication (Odstranění)

Remove malware, delete backdoors, patch vulnerabilities, reset VŠECHNA hesla! Často lepší: Nuke & Pave (kompletní reinstalace – zaručeně čisté).

🔄 Recovery (Obnova)

Restore from clean backups, rebuild, verify integrity, test, enhanced monitoring (watch for reinfection), gradual return to production. Může trvat týdny!

05

Post-Incident Activity

Lessons Learned – NIKDY nepřeskakuj!
  • Meeting celého IRT. Bez blame culture. Co fungovalo? Co ne? Co zlepšit?
  • Final Report: Executive summary, timeline, root cause, impact ($, downtime), actions, recommendations
  • Update IRP na základě lessons learned (živý dokument!)
  • Threat Intelligence Sharing: Sdílej IoCs s community (ISAC, MISP)
06

Impact Reduction

Strategie pro minimalizaci dopadu když incident nastane (100% prevence není možná).

🔲 Segmentation

Omezuje lateral movement. Malware v HR VLAN nemůže do Production.

🔐 Least Privilege

Omezená práva = omezené škody. Regular user nemůže instalovat ransomware.

💾 Backups (3-2-1)

3 kopie, 2 média, 1 offsite. Immutable backups – nelze smazat/šifrovat!

⚡ Rapid Detection

207 dní průměr → cíl < 24 h. SIEM, IDS, EDR – continuous monitoring.

🤖 Automation (SOAR)

IDS detekuje → auto-izoluje host → disable account. Rychlejší response = menší škody.

📋 DLP + Insurance

DLP brání exfiltraci dat. Cyber insurance pokryje finanční dopad (forensics, legal, notification).

07

Disaster Recovery

Obnova IT infrastruktury po katastrofální události (datacenter fire, ransomware celé infrastruktury, zemětřesení).

Klíčové metriky

RTO (Recovery Time Objective): Jak dlouho můžeme být down? E-commerce = 1 h, wiki = 24 h.

RPO (Recovery Point Objective): Kolik dat můžeme ztratit? Finance = 0, email = 4 h. RPO určuje backup frequency!

DR strategie (od nejlevnější po nejdražší)

Backup & RestoreRTO: hodiny–dny
Pilot LightRTO: hodiny
Warm StandbyRTO: min–hodiny
Hot StandbyRTO: sekundy–min

CenaNejnižšíStředníNejvyšší

DR plán BEZ testování je bezcenný! Tabletop exercise, parallel test, full interruption test – minimálně ročně.

08

Security Playbook

Dokumentované runbooks pro specifický typ incidentu. „If X happens, do Y." Standardizuje response, snižuje response time.

🔐 Ransomware Playbook

Detect: EDR alert, encrypted files, ransom note. Contain: Isolate machines, disable accounts, block C&C IPs. Investigate: Patient zero, variant, scope. Eradicate: Remove malware, check backdoors, wipe & reinstall. Recover: Restore from clean backups. DO NOT PAY!

🎣 Phishing Playbook

Detect: User report, email filter alert. Contain: If clicked → reset credentials, check malware. If entered creds → reset password NOW. Block sender domain, delete from all mailboxes. Alert all users.

📊 Data Breach Playbook

Detect: DLP alert, unusual transfer, third-party. Contain: Stop exfiltration, preserve evidence, engage legal. Investigate: What data? How much? Who? How? GDPR: 72 h notification!

🌊 DDoS Playbook

Detect: Service slowdown, bandwidth spike. Contain: Contact ISP, enable DDoS mitigation (Cloudflare, Akamai), rate limiting. Notify users.

09

SIEM

SIEM = centrální platforma: agregace logů → normalizace → korelace → alerting → dashboards → forensics.

📥AggregationLogy ze všech zdrojů
🔄NormalizationJednotný formát
🔗CorrelationPropojení events!
🚨AlertingRules + ML + IoCs
📊DashboardsSOC „single pane"
Korelace = nejdůležitější funkce!

Event 1: Failed login (firewall)
Event 2: Port scan z téže IP (IDS)
Event 3: SQL injection pokus (web server)
→ SIEM koreluje: Koordinovaný útok! HIGH PRIORITY ALERT!

Platformy: Splunk (market leader), IBM QRadar, Microsoft Sentinel (cloud), ELK Stack (open-source). Výzvy: Alert fatigue, high cost, nutný tuning.

10

DLP (Data Loss Prevention)

Prevence úniků citlivých dat. Detekuje a blokuje neoprávněné přenosy. GDPR penalty: až 4 % global revenue.

🌐 Network DLP

Data in motion. Email, web uploads, FTP. Inline na perimetru. Block/alert/encrypt.

💻 Endpoint DLP

Agent na PC. USB copy, print, screenshot. Device control – whitelist authorized USB.

💾 Storage DLP

Data at rest. Skenuje file servers, DB. Discovery + auto-classification + remediation.

☁️ Cloud DLP

O365, Google Workspace, Dropbox. API-based. File sharing monitoring.

Detekční metody
  • Content-based: Keywords („confidential"), regex (credit card: \d{4}-\d{4}-\d{4}-\d{4}), file fingerprinting
  • Context-based: Classification tags, source location (HR folder), metadata
  • Statistical/ML: Normal = 10 MB/day, najednou 10 GB → anomálie

Actions: Block, quarantine, encrypt, redact (mask CC#), alert only, user notification. Best practice: Start s discovery → classify → monitor first (alert only) → pak blocking.

Shrnutí klíčových bodů

Na zkoušku si zapamatuj

IR LIFECYCLE (NIST 4 FÁZE)

  • 1. Preparation: IRT tým, IRP plán, nástroje (SIEM, forensics), training (tabletop), prevence
  • 2. Detection & Analysis: IoC, severity (P1–P4), scope, root cause. DOKUMENTUJ VŠE!
  • 3. Containment → Eradication → Recovery: Izoluj (odpoj ze sítě), odstraň (nuke & pave), obnov (clean backups). Enhanced monitoring!
  • 4. Post-Incident: Lessons learned (no blame!), final report, update IRP, share IoCs

IMPACT REDUCTION + DR

  • Impact Reduction: Segmentation, Least Privilege, Backups 3-2-1 (immutable!), Rapid Detection (<24 h), SOAR automation, DLP, cyber insurance
  • DR metriky: RTO = jak dlouho down? RPO = kolik dat ztraceno? RPO určuje backup frequency
  • DR strategie: Backup/Restore (dny) → Pilot Light (hodiny) → Warm (min–hodiny) → Hot Standby (sekundy)
  • DR sites: Cold (prázdná budova, týdny) → Warm (HW ready, dny) → Hot (mirror, hodiny). TESTUJ!

PLAYBOOK + SIEM + DLP

  • Playbook: Runbook pro specifický incident. Ransomware (DO NOT PAY!), Phishing, Data Breach (GDPR 72 h!), DDoS
  • SIEM: Aggregation → Normalization → Correlation (nejdůležitější!) → Alerting → Dashboards. Splunk, Sentinel, ELK
  • DLP: Network (in motion), Endpoint (USB/print), Storage (at rest), Cloud. Content/Context/ML detekce. Block/encrypt/alert
  • Není otázka JESTLI incident nastane, ale KDY. Příprava je klíčová! 207 dní detekce → cíl < 24 h
