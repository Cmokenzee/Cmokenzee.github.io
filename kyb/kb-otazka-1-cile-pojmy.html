01

CIA triáda

Tři základní pilíře kybernetické bezpečnosti – Confidentiality, Integrity, Availability.

🔒 Confidentiality Kdo to vidí?
🛡️ Integrity Jsou data správná?
⚡ Availability Funguje to, když potřebuju?
02

Confidentiality (Důvěrnost)

Data vidí jen ti, kdo mají oprávnění. Šifrování (AES symetrická, RSA asymetrická), autentizace (kdo jsi?), autorizace (co smíš?).

Příklady porušení
  • Man-in-the-Middle: Útočník na veřejné Wi-Fi odposlouchává komunikaci
  • Data breach: 2013 Yahoo – ukradena data 3 miliard uživatelů
  • Shoulder surfing: Někdo se dívá přes rameno při zadávání PINu
Ochrana
  • HTTPS (zelený zámek v prohlížeči)
  • VPN při veřejné Wi-Fi
  • Šifrování disku (BitLocker, FileVault)
  • 2FA – dvoufaktorová autentizace
03

Integrity (Integrita)

Data jsou správná, kompletní a nezměněná. Nikdo je nepozměnil.

Příklady porušení
  • Ransomware: Virus zašifruje soubory → data změněna (nemůžeš je použít)
  • SQL Injection: Útočník změní dotaz do DB. Místo přihlášení zadá ' OR '1'='1 a dostane se všude
  • Manipulace s logy: Smazání záznamů aby nebylo vidět průnik
Ochrana
  • Hash funkce (SHA-256): „otisk" souboru – pokud se liší, soubor byl změněn
  • Digitální podpis: garantuje autora + nezměněnost
  • Checksums (CRC): kontrolní součty při přenosu
  • Logování: kdo, kdy, co změnil
04

Availability (Dostupnost)

Systém musí fungovat, když ho potřebuješ. Nemůže být „dole".

Příklady porušení
  • DDoS (2016 Dyn): Miliony požadavků → vyřadilo Twitter, Netflix, Reddit, Spotify
  • WannaCry (2017): Ransomware na britské NHS → rušení operací
  • Fyzické: Požár v datacentru, povodeň, výpadek elektřiny, HW selhání
Ochrana
  • Zálohy 3-2-1: 3 kopie, 2 různá média, 1 offsite
  • Redundance: více serverů, failover
  • Load balancing: rozdělení zátěže
  • UPS: záložní zdroj. CDN: distribuovaný obsah
  • Rate limiting: omezení požadavků z jedné IP
05

Hrozby – interní vs externí

Interní hrozby

Úmyslné: Snowden (NSA leak), zaměstnanec krade data, admin maže servery před výpovědí.
Neúmyslné: Klik na phishing, notebook v kavárně, slabé heslo „jmeno123". 95 % incidentů = lidský faktor!

Externí hrozby

Organizovaný zločin: ransomware, krádeže kreditek. Státní aktéři (APT): špionáž, SolarWinds 2020. Hacktivisté: Anonymous. Script kiddies: pro zábavu.

Proč jsou interní hrozby nebezpečné?

Mají legitimní přístup – prochází kontrolami. Znají vnitřní systémy. Důvěřuje se jim. Těžko se detekují.

06

Zranitelnosti a zneužití

Software

Buffer Overflow: pošli 1000 znaků místo 10 → code execution. SQL Injection: admin'-- obejde přihlášení. XSS: škodlivý JS v komentáři.

Konfigurace

Výchozí hesla (admin/admin). Otevřené porty. Zbytečné služby.

Hardware

Spectre/Meltdown: chyba v CPU, čtení cizí paměti. Keylogger: HW zařízení mezi klávesnicí a PC.

Social Engineering

Phishing: falešný email banky. Pretexting: „jsem z IT, potřebuji heslo". Baiting: USB „Výplaty 2024" na parkovišti.

SQL Injection – jak to funguje
-- Normální dotaz:
SELECT * FROM users WHERE name = 'Jan' AND password = 'heslo123'

-- Útočník zadá jméno: admin'--
SELECT * FROM users WHERE name = 'admin'--' AND password = 'heslo123'

-- = komentář v SQL → vše za ním ignorováno → přihlášení BEZ hesla!

Fáze útoku (Cyber Kill Chain)

1ReconnaissancePrůzkum: LinkedIn, web firmy, Shodan, WHOIS, sociální sítě
2WeaponizationPříprava: infikovaný PDF s exploitem, phishingová stránka
3DeliveryDoručení: spear-phishing email „Faktura za služby…"
4ExploitationZneužití: oběť otevře PDF → exploit v Adobe Reader → malware
5InstallationInstalace: backdoor na port 4444, autostart, vypne antivir
6Command & ControlC2: malware se připojí k útočníkovu serveru (přes TOR)
7Actions on Obj.Cíl: lateral movement, domain admin, stažení dat / ransomware
08

Typy hackerů

🤍White Hat
Etický hacker. Bug bounty, pen-testing, security audit. Najímaný firmami.
🖤Black Hat
Kriminální. Ransomware, krádež dat, špionáž. APT28, Lazarus, REvil.
🩶Grey Hat
Hackne bez povolení, pak informuje. Hraničí s vydíráním.
👶Script Kiddie
Stáhne hotový tool (LOIC), nerozumí jak funguje. Chytí se snadno.
✊Hacktivist
Politické motivy. Anonymous, LulzSec. DDoS, defacement, leak.
🏛️State-Sponsored
APT. Obrovské zdroje, vlastní zero-days. Stuxnet, NotPetya, APT29.
09

Zero-Day Attacks

Zero-day = zranitelnost neznámá výrobci. Vývojáři měli 0 dní na přípravu opravy. Žádná obrana!

Životní cyklus zero-day

1. Objevení
Výzkumník/hacker najde chybu → nahlásí (bug bounty) nebo prodá na černém trhu (miliony $)
2. Zneužívání „in the wild"
Útočník exploit používá, nikdo neví. Může trvat dny až roky
3. Odhalení
Bezp. firma zpozoruje podivnou aktivitu → analýza → informuje výrobce
4. Patch Development
Výrobce pracuje na opravě (dny–týdny)
5. Patch Release
Aktualizace vydána → od teď už to není zero-day. Ale ne všichni aktualizují!
6. Post-disclosure
Závodí: kdo rychleji? Ti co patchují vs ti co útočí na neaktualizované
Slavné zero-day příklady
  • Stuxnet (2010): 4 zero-days najednou! USA+Izrael zničili íránské centrifugy. Cena: desítky mil. $
  • EternalBlue (2017): Windows SMB exploit vyvinutý NSA, ukraden, zveřejněn → WannaCry + NotPetya
  • Log4Shell (2021): Log4j (Java) – 1 řádek kódu v Minecraft chatu = napadený server
  • Pegasus (NSO Group): iOS/Android zero-click exploit. Odposlech novinářů, politiků
Černý trh s zero-days (ceny 2024)
ExploitCena
iOS remote jailbreak$2–3 miliony
Android full chain$2.5 milionu
Windows RCE$100K–$500K
Chrome/Safari sandbox escape$500K+

Kupují: vlády, zpravodajské služby, NSO Group, Hacking Team.

Obrana proti zero-days

Defense in Depth

Vícevrstvá obrana: firewall + IDS + antivirus + segmentace + least privilege

Behavior Detection

Hledej podezřivé chování (Word se normálně nepřipojuje k internetu)

Sandboxing

Izolované prostředí pro podezřelé programy

Zero Trust

„Nikdy nedůvěřuj, vždy ověřuj" – i ve firemní síti autentizace pro každý systém

Shrnutí klíčových bodů

Na zkoušku si zapamatuj

CIA TRIÁDA

  • C (Confidentiality): kdo vidí data? Ochrana: HTTPS, VPN, šifrování, 2FA
  • I (Integrity): jsou data správná? Ochrana: hash (SHA-256), digitální podpis, logování
  • A (Availability): funguje to? Ochrana: zálohy 3-2-1, redundance, load balancing, UPS

HROZBY A ZRANITELNOSTI

  • Interní: úmyslné (insider theft) + neúmyslné (phishing klik, slabé heslo). 95 % = lidský faktor!
  • Externí: organizovaný zločin, státní aktéři (APT), hacktivisté, script kiddies
  • Zranitelnosti: SW (buffer overflow, SQLi, XSS), konfigurace, HW (Spectre), social engineering

FÁZE ÚTOKU (KILL CHAIN)

  • 7 fází: Reconnaissance → Weaponization → Delivery → Exploitation → Installation → C2 → Actions

HACKEŘI A ZERO-DAY

  • White Hat (etický), Black Hat (kriminální), Grey Hat (bez povolení ale informuje), Script Kiddie, Hacktivist, State-Sponsored (APT)
  • Zero-day: neznámá zranitelnost, 0 dní na patch. Stuxnet (4 zero-days!), EternalBlue→WannaCry, Log4Shell, Pegasus
  • Obrana: Defense in Depth, behavior detection, sandboxing, Zero Trust, aktualizovat ASAP!
