01

Timer vs Counter

Timer/Counter = hardwarový modul MCU, který autonomně počítá na základě hodinového signálu nebo externích událostí. Běží nezávisle na CPU!

TIMER (Časovač)

Počítá interní clock (CPU clock / prescaler). Měření času – delay, periodic interrupts, PWM.

COUNTER (Čítač)

Počítá externí události na pinu (T0, T1). Rotační enkodér, flow meter, frequency counter.

Proč hardware timer (ne software delay)?
  • Přesnost – HW timer běží nezávisle na CPU
  • Autonomie – CPU může dělat jiné věci
  • Deterministický – přesný timing bez jitteru
  • Efektivita – žádné plýtvání CPU cykly na while(delay--)

03

Předdělička (Prescaler)

Dělička frekvence před timerem. Snižuje clock → umožňuje měřit delší časy.

Problém bez prescaleru

8-bit timer, CPU 16 MHz, prescaler = 1: Max count = 255. Overflow time = 255 / 16 000 000 = 15.9 μs → příliš rychlé!

S prescalerem 1024: Timer clock = 16 MHz / 1024 = 15 625 Hz. Overflow = 255 / 15 625 = 16.3 ms → rozumné!

Timer_freq = CPU_clock / Prescaler
Overflow_time = Max_count × (1 / Timer_freq)

Trade-off

Menší prescaler = vyšší rozlišení, kratší max čas. Větší prescaler = nižší rozlišení, delší max čas.

04

Normal Mode (Overflow)

Nejjednodušší režim. Timer počítá od 0 do MAX, pak overflow → interrupt → vrátí se na 0.

NORMAL MODE – 8-BIT TIMER
TCNT: 0 → 1 → 2 → ... → 254 → 255 → 0 (OVF!) → 1 → 2 → ...
↑ TOV flag nastaven → interrupt (pokud povolen)

Použití: Periodické interrupty, software RTC, periodic task execution.

Příklad kódu (AVR – Timer0 Overflow)
// Timer0, prescaler 1024 → overflow každých 16.3 ms
TCCR0B |= (1<<CS02) | (1<<CS00); // Prescaler 1024
TIMSK0 |= (1<<TOIE0); // Enable overflow interrupt

ISR(TIMER0_OVF_vect) {
  // Volá se každých ~16.3 ms
}
05

CTC Mode (Clear Timer on Compare Match)

Timer počítá od 0 do OCRx, pak se automaticky resetuje na 0. Přesné periodické intervaly!

CTC MODE
TCNT: 0 → 1 → 2 → ... → OCRx (match!) → 0 → 1 → 2 → ... → OCRx → 0
↑ OCF flag → interrupt + TCNT reset. Nastavitelná perioda změnou OCRx!
Výhoda oproti Normal mode

Přesný interval – nemusíš čekat na overflow (255). Změň OCRx = změň interval. Žádný offset error.

OCRx = (CPU_clock / (Prescaler × Desired_freq)) − 1
Příklad: 1 kHz interrupt, 16 MHz CPU, prescaler 64 → OCR = (16M / (64 × 1000)) − 1 = 249
Příklad kódu (AVR – CTC 1 kHz)
// CTC mode, 1 kHz interrupt (každou 1 ms)
TCCR0A |= (1<<WGM01); // CTC mode
TCCR0B |= (1<<CS01) | (1<<CS00); // Prescaler 64
OCR0A = 249; // Compare value
TIMSK0 |= (1<<OCIE0A); // Compare match interrupt

ISR(TIMER0_COMPA_vect) {
  // Volá se přesně každou 1 ms
}
06

Input Capture Mode

Zachytí (capture) aktuální hodnotu timeru při edge na pinu (ICP). Měření času mezi událostmi – hardwarově, bez CPU intervention!

Jak to funguje
1
Timer běží kontinuálně (free-running)
2
Edge na ICP pinu (rising/falling)
ICES bit: 1 = rising edge, 0 = falling edge
3
TCNT okamžitě zkopírován do ICR (Input Capture Register)
4
ICF flag → interrupt (pokud povolen)

Aplikace Input Capture

Měření frekvence

Čas mezi dvěma rising edges → perioda → freq = 1/perioda. Rising 1: time1 → Rising 2: time2 → Period = time2 − time1.

Měření duty cycle

Rising: t1 → Falling: t2 → Rising: t3. HIGH_time = t2−t1. Period = t3−t1. Duty = HIGH/Period × 100%.

Ultrazvuk (HC-SR04)

Echo pin: rising → start, falling → end. Duration = end − start. Distance = Duration_μs / 58 [cm].

07

Output Compare Mode

Timer porovnává TCNT s OCRx. Když TCNT == OCRx → automatická akce na output pinu. Základ pro PWM!

Akce při matchPopis
NormalŽádná akce na pinu (jen interrupt)
TogglePin se přepne (LOW↔HIGH) → square wave
ClearPin → LOW
SetPin → HIGH
Toggle: Output_freq = Timer_freq / (2 × (OCRx + 1))
Příklad: 1 kHz tone, 250 kHz timer → OCR = (250000 / (2 × 1000)) − 1 = 124

PWM – princip

PWM (Pulse Width Modulation) = simulace analogového výstupu digitálním signálem. Mění duty cycle (poměr HIGH/LOW) při konstantní frekvenci.

Klíčové parametry
  • Frequency – jak rychle se opakuje cyklus (Hz)
  • Duty Cycle – % času kdy signál HIGH
  • Resolution – kolik kroků (8-bit = 256 kroků)

09

Fast PWM

Timer počítá od 0 do MAX (255), pak se okamžitě resetuje. Nejvyšší frekvence PWM.

FAST PWM (NON-INVERTED)
TCNT: 0 ──▲── OCRx ──▲── MAX → 0
OCx pin: ▔▔▔▔▔▔▔▔▁▁▁▁▁▁▁▁▁
TCNT=0 → pin HIGH | TCNT=OCRx → pin LOW | TCNT=MAX → reset
Duty_cycle = OCRx / (MAX + 1) × 100%
PWM_freq = Timer_freq / (MAX + 1)
Příklad: 8-bit Fast PWM

CPU 16 MHz, prescaler 64: Timer_freq = 250 kHz. PWM_freq = 250000 / 256 = 976 Hz.

  • OCR = 0 → 0% duty
  • OCR = 128 → 50% duty
  • OCR = 255 → 100% duty (téměř)
Příklad kódu (AVR – Fast PWM Timer0)
// Fast PWM, non-inverted, prescaler 64
TCCR0A |= (1<<WGM01) | (1<<WGM00); // Fast PWM
TCCR0A |= (1<<COM0A1); // Non-inverted output
TCCR0B |= (1<<CS01) | (1<<CS00); // Prescaler 64

OCR0A = 128; // 50% duty cycle
// OC0A pin (PD6) nyní generuje PWM!
10

Phase-Correct PWM

Timer počítá UP (0→MAX), pak DOWN (MAX→0). Symetrický PWM. Polovina frekvence Fast PWM, ale lepší pro motory.

PHASE-CORRECT PWM
TCNT: 0 → MAX → 0 → MAX → 0 ...
       ▲       ▼   ▲       ▼
PWM_freq = Timer_freq / (2 × MAX)
→ Polovina frekvence Fast PWM
Kdy co použít?

Fast PWM – LED dimming, audio, high-freq signály (max frekvence).

Phase-Correct – motor control, když potřebuješ symetrii (méně harmonických).

11

PWM aplikace

LED Dimming

Oko vidí průměrný jas. PWM > 100 Hz → žádné blikání. OCR0A = brightness (0–255). Pin → [R 220Ω] → LED → GND.

DC Motor Speed

Duty cycle = rychlost. Motor driver nutný (L293D, MOSFET). 0% = stojí, 100% = plná rychlost.

Audio/Tone

50% duty = square wave. Změň frekvenci = změň tón. Střední C (261 Hz): OCR ≈ 477.

Analog Output (DAC)

PWM + RC low-pass filter → analogové napětí. V_out = Vcc × (OCR/255).

Servo Motor Control

Servo potřebuje PWM s periodou 20 ms (50 Hz). Pozice = délka HIGH pulzu (1–2 ms).

0° 1.0 ms pulse
90° 1.5 ms pulse
180° 2.0 ms pulse
SERVO PWM – PULZ V 20 ms RÁMCI (50 Hz)
Servo konfigurace (16-bit timer)
// 50 Hz PWM, CPU 16 MHz, prescaler 8
// Timer freq = 2 MHz → 20 ms = 40000 ticks
ICR1 = 40000; // TOP (20 ms period)

OCR1A = 2000; // 0° (1.0 ms)
OCR1A = 3000; // 90° (1.5 ms)
OCR1A = 4000; // 180° (2.0 ms)
12

Shrnutí klíčových bodů

Na zkoušku si zapamatuj

TIMER / COUNTER / PRESCALER

  • Timer = interní clock (měření času). Counter = externí události (počítání pulzů)
  • Prescaler dělí clock → delší časy. Trade-off: rozlišení vs rozsah
  • Registry: TCNTx (počítá), TCCRx (config), OCRx (compare), ICRx (capture)

REŽIMY

  • Normal – overflow interrupt (0→MAX→0). Periodické úlohy
  • CTC – compare match (0→OCRx→0). Přesné intervaly! OCR = (CPU / (Prescaler × freq)) − 1
  • Input Capture – zachytí TCNT při edge. Měření frekvence, duty cycle, ultrazvuk
  • Output Compare – akce na pinu (Toggle/Clear/Set). Základ pro PWM

PWM

  • Fast PWM – max frekvence (0→MAX→0). freq = Timer_freq / (MAX+1). LED, audio
  • Phase-Correct – symetrický (0→MAX→0→MAX). freq = Timer/(2×MAX). Motory
  • Duty cycle = OCRx / (MAX+1) × 100%. V_avg = Vcc × duty
  • Aplikace: LED dimming (>100 Hz), servo (50 Hz, 1–2 ms), DC motor, audio, DAC (+ RC filtr)
  • Servo: 20 ms perioda. 1 ms = 0°, 1.5 ms = 90°, 2 ms = 180°
