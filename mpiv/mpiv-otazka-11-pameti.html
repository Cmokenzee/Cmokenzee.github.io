01

Úvod do pamětí

Paměť uchovává data a instrukce. Rychlost a kapacita paměti zásadně ovlivňuje výkon celého systému.

Základní dělení
  • Volatilní – data zmizí po odpojení napájení (RAM)
  • Non-volatilní – data zůstanou (Flash, SSD, HDD)
RAM (Random Access Memory)

Volatilní paměť pro aktivní data. „Random Access" = přístup k libovolné adrese trvá stejně dlouho.

  • SRAM (Static RAM) – rychlá, drahá → cache
  • DRAM (Dynamic RAM) – pomalejší, levnější → hlavní paměť

03

DIMM, Timings a kanály

DIMM (Desktop)

Plná velikost ~133 mm. 288 pinů (DDR4/DDR5).

SO-DIMM (Laptop)

Poloviční ~67 mm. 260 pinů (DDR4), 262 (DDR5). Stejné frekvence.

CAS Latency (CL) a Timings

CL = počet clock cycles mezi příkazem READ a prvním bitem dat. NIŽŠÍ = LEPŠÍ.

Timing notace: DDR4-3200 CL16-18-18-38
  • CL (CAS Latency): 16 cycles
  • tRCD (RAS to CAS Delay): 18 cycles
  • tRP (RAS Precharge): 18 cycles
  • tRAS (Row Active Time): 38 cycles
Latence (ns) = (CL / Frekvence) × 2000
DDR4-3200 CL16: (16/3200)×2000 = 10 ns │ DDR5-6000 CL30: (30/6000)×2000 = 10 ns
DDR5 vs DDR4 latence

DDR5 má vyšší CL čísla, ale díky vyšší frekvenci je skutečná latence podobná (~10 ns). DDR5 ale nabízí 2× bandwidth!

Dual-Channel, Quad-Channel

Dual-channel pravidlo

Potřeba 2 moduly ve správných slotech (typicky slot 2 + 4). Dual-channel = 2× bandwidth zdarma! DDR5: dual-channel per DIMM → MB dual-channel = 4× 32-bit = 128-bit total.

SRAM parametry
  • RYCHLÁ – typicky <1 ns access time
  • Žádný refresh – jednodušší kontrolér
  • Nízká latence – okamžitá odezva
  • DRAHÁ – 6 tranzistorů per bit! (~$100/MB)

  • Registry procesoru
  • Network switch buffery, FPGA block RAM

Typické velikosti: L1 = 32–64 KB, L2 = 256–512 KB, L3 = 16–96 MB.

DRAM parametry
  • POMALEJŠÍ než SRAM – typicky 10–50 ns access
  • Potřeba refresh – každých ~64 ms pro celou paměť
  • LEVNÁ – jen 1 tranzistor per bit! (~$0.01/MB)
  • Vysoká density – velká kapacita na malé ploše
Kde se používá DRAM
  • Hlavní RAM systému (DDR4/DDR5)
  • GPU VRAM (GDDR6, HBM)
  • Smartphone RAM (LPDDR)

Proč ne všechno SRAM?

32 GB SRAM by stálo ~$3 000 000 a fyzicky by se nevešlo na motherboard! Proto existuje hierarchie: malá rychlá SRAM cache + velká levná DRAM.

07

Paměťová hierarchie

Trade-off rychlost vs. kapacita vs. cena. Malá rychlá drahá blízko CPU, velká pomalá levná dále.

Registry<0.5 ns │ ~bytes
L1 Cache (SRAM)~1 ns │ 32–64 KB
L2 Cache (SRAM)~3–5 ns │ 256–512 KB
L3 Cache (SRAM)~10–20 ns │ 16–96 MB
RAM (DRAM – DDR5)~50–100 ns │ 8–128 GB
SSD (Flash NAND)~10–100 μs │ 256 GB – 4 TB
HDD (magnetické)~5–10 ms │ 1–20 TB
Proč hierarchie funguje – Locality
  • Temporal Locality (časová) – data právě použitá budou brzy znovu. Příklad: loop variable i
  • Spatial Locality (prostorová) – data blízko právě použitých budou brzy použita. Příklad: array prvky vedle sebe

09

Cache – organizace a mapping

Cache Line

Základní jednotka přenosu. Typicky 64 bytů. Cache VŽDY načítá celou line → využívá spatial locality.

Cache Mapping – 3 typy

Direct Mapped

Každá adresa → přesně 1 cache line. Jednoduchý, ale konflikty (thrashing).

Fully Associative

Jakákoli adresa → jakákoli line. Žádné konflikty, ale drahé (prohledání všech).

N-way Set Associative ✓

STANDARD! Adresa → 1 set, ale libovolná line v setu. Typicky 8-way nebo 16-way. Dobrý kompromis.

Replacement Policy – co vyhodit?
  • LRU (Least Recently Used) – vyhazuj nejdéle nepoužitou. Nejběžnější!
  • FIFO (First In First Out)
  • Random, LFU (Least Frequently Used)
10

Hit, Miss, Hit Rate

Cache Hit ✓

Data V cache → rychlé čtení (~1–20 ns).

Cache Miss ✗

Data MIMO cache → čtení z RAM (~50–100 ns) nebo nižší úrovně.

Typy Cache Miss

Cold Miss (Compulsory)

První přístup – cache ještě nemá data. Program startuje, cache prázdná.

Capacity Miss

Cache příliš malá – data vyhozena kvůli kapacitě. Working set > cache size.

Conflict Miss

2 adresy mapují na stejný set a vyhazují se navzájem (thrashing).

Hit Rate a Miss Rate

Hit Rate = Hits / Total   │   Miss Rate = Misses / Total
Hit Rate + Miss Rate = 1 (100%)
Příklad

1000 přístupů: 950 hitů, 50 missů

Hit Rate = 95%

AMAT a write politiky

Average Memory Access Time (AMAT)

AMAT = Hit_Time + (Miss_Rate × Miss_Penalty)
Příklad: jednoúrovňová cache
L1 Hit Time = 1 ns
L1 Miss Rate = 5%
RAM (miss penalty) = 100 ns

AMAT = 1 + (0.05 × 100) = 1 + 5 = 6 ns
Příklad: víceúrovňová cache (L1 + L2)
L1 Hit = 1 ns, Miss Rate = 5%
L2 Hit = 5 ns, Miss Rate = 20% (z L1 missů)
RAM = 100 ns

AMAT = 1 + 0.05 × (5 + 0.20 × 100)
     = 1 + 0.05 × 25 = 2.25 ns (mnohem lepší!)
Dopad Hit Rate na výkon

I malé zlepšení hit rate má MASIVNÍ dopad!

95% hit rate → AMAT = 6 ns

99% hit rate → AMAT = 2 ns (3× rychlejší!)

Write politiky

Write-Through

Zápis do cache A SOUČASNĚ do RAM. Vždy konzistentní. Pomalé – každý write jde do RAM.

Write-Back ✓ (moderní CPU)

Zápis JEN do cache. Do RAM až při eviction. Dirty bit značí změněná data. Rychlé!

Write Miss – co když adresa není v cache?
  • Write-Allocate: načti line z RAM do cache, pak zapiš (s write-back)
  • No-Write-Allocate: zapiš přímo do RAM, cache neaktualizuj (s write-through)
12

Shrnutí klíčových bodů

Na zkoušku si zapamatuj

DDR SDRAM

  • DDR3: 1.5 V, 800–2133 MHz, ~17 GB/s
  • DDR4: 1.2 V, 2133–5000 MHz, ~25.6 GB/s. Mainstream 2015–2023
  • DDR5: 1.1 V, 4800–8400 MHz, ~67.2 GB/s. On-die ECC, dual-channel per DIMM
  • Timings: CL-tRCD-tRP-tRAS. Latence = (CL/freq)×2000 ns
  • Dual-channel = 2× bandwidth (správné sloty!)

SRAM vs DRAM

  • SRAM: 6T cell, <1 ns, žádný refresh, drahá → cache (L1/L2/L3)
  • DRAM: 1T1C cell, 10–50 ns, refresh každých 64 ms, levná → hlavní RAM

PAMĚŤOVÁ HIERARCHIE

  • Registry (<0.5 ns) → L1 (1 ns, 32–64 KB) → L2 (3–5 ns, 256–512 KB) → L3 (10–20 ns, 16–96 MB) → RAM (50–100 ns) → SSD (μs) → HDD (ms)
  • Funguje díky locality: temporal (brzy znovu) + spatial (blízko sebe)

CACHE

  • L1: per-core, split i/d, ~1 ns │ L2: per-core, unified, ~3–5 ns │ L3: shared, ~10–20 ns
  • Cache line: 64 bytů │ Mapping: N-way set associative (8/16-way)
  • Replacement: LRU (Least Recently Used) – nejběžnější

HIT / MISS / AMAT

  • Hit: data v cache (rychlé) │ Miss: data mimo cache (pomalé)
  • Miss typy: cold (první přístup), capacity (malá cache), conflict (thrashing)
  • Hit Rate: L1 = 95–99%. I malé zlepšení = masivní dopad!
  • AMAT = Hit_Time + (Miss_Rate × Miss_Penalty). Příklad: 1 + 0.05×100 = 6 ns
  • Write: Write-Through (pomalé, konzistentní) vs Write-Back (rychlé, dirty bit, moderní CPU)
Zlatá pravidla
  • DDR5 = budoucnost (67 GB/s, on-die ECC)
  • SRAM rychlá/drahá (cache), DRAM pomalá/levná (RAM) – proto hierarchie
  • Locality (temporal + spatial) = důvod proč cache funguje
  • Hit rate 95% → 99% = 3× rychlejší! I malé zlepšení se počítá
  • N-way set associative + LRU = standard moderních cache
