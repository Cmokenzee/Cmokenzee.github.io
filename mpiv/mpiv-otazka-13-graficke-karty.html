GPU – úvod a CPU vs GPU

GPU (Graphics Processing Unit) = specializovaný procesor pro PARALELNÍ zpracování. Na rozdíl od CPU (několik silných jader) má GPU TISÍCE menších jader optimalizovaných pro floating-point matematiku.

CPU vs GPU filosofie
CPUGPU
JádraNěkolik rychlých (4–24)Tisíce pomalých (5000–20000+)
ZaměřeníSekvenční úlohyMasivní paralelismus
OptimalizaceNízká latenceVysoká propustnost
Použití GPU
  • Gaming – 3D grafika v reálném čase
  • 3D rendering – Blender, Maya, Cinema 4D
  • Video editing – Premiere, DaVinci Resolve
  • Machine Learning / AI – CUDA, TensorFlow, PyTorch
  • Scientific computing – simulace, kryptografie

Integrated GPU (iGPU)

Zabudované v CPU. Sdílí RAM. Light gaming, video. Intel Iris Xe, AMD Radeon Graphics.

Discrete GPU (dGPU)

Samostatná karta v PCIe slotu. Vlastní VRAM. Gaming, profesionální, AI.

Mikroarchitektura GPU – SM, CUDA, Warp

GPU = masivně paralelní. Tisíce jader vykonávají STEJNOU operaci na různých datech (SIMD – Single Instruction Multiple Data).

NVIDIA: Streaming Multiprocessor (SM)

STREAMING MULTIPROCESSOR (SM) – BUILDING BLOCK
CUDA Cores – integer/float ALU (stovky per SM)
Tensor Cores – matrix multiply (AI/ML)
RT Cores – ray tracing acceleration
Warp Scheduler – řídí 32-thread warps
Register File + Shared Memory / L1 Cache
CUDA Core

Nejmenší výpočetní jednotka. Provádí jednu FP nebo INT operaci per clock. RTX 4090 = 16 384 CUDA cores!

Warp (32 threads)

Skupina 32 vláken vykonávaných SOUČASNĚ na SM. Všechna vlákna provádějí STEJNOU instrukci (SIMT – Single Instruction Multiple Thread).

Příklad: 32 vláken, každé zpracovává 1 pixel → všechny současně ADD operace.

Divergence problém

Když vlákna ve warp berou RŮZNÉ cesty (if/else), warp musí vykonat OBOJE sekvenčně → pomalé!

if (threadId % 2 == 0) { A } else { B }
→ 50% warp čeká při A, 50% při B → 50% efektivita!

AMD: Compute Unit (CU)

AMD RDNA ekvivalenty
  • Compute Unit (CU) – ekvivalent NVIDIA SM
  • Stream Processors – ekvivalent CUDA Cores (64 per CU)
  • Wavefront = 32 threads (AMD ekvivalent warp)
  • Infinity Cache – 96 MB L3 cache (redukuje BW požadavky)

Tensor Cores, RT Cores, DLSS

Tensor Cores

Specializovaná jádra pro matrix multiply-accumulate. 4×4 matrix operace per clock! Kritické pro AI/ML a DLSS (neural network inference).

GDDR vs HBM

GDDR6 / GDDR6X

Consumer standard. Chipy okolo GPU na PCB. GDDR6X: až 24 Gbps. RTX 4090: 384-bit bus = ~1000 GB/s. Levnější, až 24 GB.

HBM (High Bandwidth Memory)

Datacenter/professional. Stackovaná vertikálně nad/pod GPU die (TSV). HBM3: 3+ TB/s! Extrémní BW, nízká spotřeba. VELMI DRAHÉ.

GDDR6X: ~1 000 GB/s (consumer)  │  HBM3: ~3 000 GB/s (datacenter)

HDMI

HDMI (High-Definition Multimedia Interface, 2002) – digitální video + audio v jednom kabelu. Nejrozšířenější pro consumer electronics (TV, konzole).

VerzeBandwidthMax rozlišeníKlíčové features
HDMI 1.4 (2009)10.2 Gbps4K @ 30 Hz1080p @ 120 Hz
HDMI 2.0 (2013)18 Gbps4K @ 60 HzHDR support, 1080p @ 240 Hz
HDMI 2.1 (2017)48 Gbps4K @ 120 Hz, 8K @ 60 HzVRR, eARC, DSC, gaming standard
HDMI 2.1 features
  • VRR (Variable Refresh Rate) – G-Sync/FreeSync kompatibilní
  • eARC (Enhanced Audio Return Channel) – high-quality audio zpět do soundbaru
  • DSC (Display Stream Compression) – komprese pro vyšší rozlišení
  • Standard pro PS5, Xbox Series X, RTX 4000
HDMI konektory
  • Type A (Standard) – plná velikost, GPU/TV
  • Type C (Mini) – tablety, kamery
  • Type D (Micro) – smartphones

Zastaralé: VGA a DVI

VGA (1987)

Analogový RGB, 15-pin D-sub. Max 1080p@60. Žádné audio. Moderní GPU NEMAJÍ VGA.

DVI (1999)

Digitální, max 2560×1600@60. Žádné audio. Dual-Link pro vyšší rozlišení. Postupně vyřazováno.

DisplayPort

DisplayPort (VESA 2006) – navrženo pro PC monitory. Royalty-free (na rozdíl od HDMI). Packet-based přenos. Podpora MST (Multi-Stream Transport) – daisy-chain monitorů.

USB-C Alt Mode a Thunderbolt

USB-C DisplayPort Alt Mode

USB-C přenáší DP signál + USB data + power. 1 kabel = video + data + nabíjení. 4K @ 60 Hz (DP 1.4). Běžné na laptopech.

Thunderbolt 3/4

40 Gbps. DP + PCIe + USB + Power. 2× 4K@60 nebo 1× 5K@60. eGPU support – externí grafika!

Kdy co použít?
  • Gaming PC → monitor: DisplayPort (VRR, vyšší refresh)
  • Gaming PC → TV: HDMI 2.1 (4K @ 120 Hz)
  • Laptop → monitor: USB-C Alt Mode nebo Thunderbolt
  • Multi-monitor: DisplayPort MST (daisy-chain)

Shrnutí klíčových bodů

Na zkoušku si zapamatuj

GPU ZÁKLADY + VÝROBCI

  • GPU = tisíce jader paralelně (vs CPU několik sekvenčně). SIMD/SIMT
  • NVIDIA RTX 4090: 16 384 CUDA, 24 GB GDDR6X, 450W, 4K 120+ FPS, $1 600
  • AMD RX 7900 XTX: 6 144 SP, 24 GB GDDR6, lepší cena/výkon, horší RT
  • Intel Arc A770: nový hráč, 16 GB, XeSS, driver zlepšování
  • DLSS 3.5 (AI, Tensor) vs FSR 3 (open-source, jakákoli GPU)

MIKROARCHITEKTURA

  • NVIDIA SM: CUDA Cores (ALU) + Tensor Cores (AI) + RT Cores (ray tracing) + Warp Scheduler
  • Warp = 32 threads SIMT. Divergence (if/else) → sekvenční → pomalé!
  • AMD CU: Stream Processors (64/CU), Wavefront = 32 threads, Infinity Cache
  • Paměť: Registers → Shared/L1 (20–30 cy) → L2 (200 cy) → VRAM (400–800 cy)

GDDR vs HBM + RENDERING

  • GDDR6X: ~1 000 GB/s (consumer). HBM3: ~3 000 GB/s (datacenter, drahé)
  • Rasterizace: Vertex Shader → Rasterization → Pixel Shader → ROP
  • Ray Tracing: Ray Gen → BVH Traversal (RT Cores!) → Hit/Miss → Rekurze

VIDEO ROZHRANÍ

  • VGA: analogový, zastaralý │ DVI: digitální, žádné audio, vyřazováno
  • HDMI 2.1: 48 Gbps, 4K@120, 8K@60, VRR, eARC. Standard TV/konzole
  • DisplayPort 2.1: 80 Gbps, 4K@240, 8K@120, MST, royalty-free. Lepší pro PC
  • USB-C Alt Mode: DP over USB-C, video+data+power jedním kabelem
  • Thunderbolt 3/4: 40 Gbps, DP+PCIe+USB, eGPU support
Zlatá pravidla
  • GPU = masivní paralelismus. NVIDIA dominuje (80%), AMD lepší cena/výkon
  • Warp = 32 threads SIMT. Tensor Cores = AI (DLSS), RT Cores = ray tracing HW
  • GDDR6X ~1 TB/s (consumer), HBM3 ~3 TB/s (datacenter)
  • HDMI 2.1 = 48 Gbps (TV/konzole), DP 2.1 = 80 Gbps (PC monitory, MST)
  • Gaming PC → monitor: DisplayPort. PC → TV: HDMI 2.1. Laptop: USB-C / TB
