01

GPIO piny a organizace

GPIO (General Purpose Input/Output) = programovatelné digitální piny MCU. Konfigurovatelné jako vstup nebo výstup. Organizovány do portů (skupina 8 nebo 16 pinů).

Příklad ATmega328 (Arduino Uno)
  • PORTB – piny PB0 až PB7 (8 pinů)
  • PORTC – piny PC0 až PC5 (6 pinů)
  • PORTD – piny PD0 až PD7 (8 pinů)

Řídící registry (DDR, PORT, PIN)

Každý GPIO port je řízen třemi registry:

DDRx – Data Direction Register

Určuje směr pinu: 0 = INPUT, 1 = OUTPUT. 1 bit na pin.

PORTx – Port Output Register

Když OUTPUT: určuje logickou úroveň (1=HIGH/Vcc, 0=LOW/GND).

Když INPUT: 1 = pull-up enabled, 0 = High-Z (plovoucí).

PINx – Port Input Register

Read-only. Čtení aktuálního stavu pinu. Vrací 1 (HIGH) nebo 0 (LOW) – skutečná logická úroveň na pinu.

04

Konfigurace GPIO režimů

OUTPUT Push-Pull

DDR=1, PORT=0/1
Pin aktivně řídí HIGH (P-MOS → Vcc) nebo LOW (N-MOS → GND). Source i sink current.

INPUT s Pull-up

DDR=0, PORT=1
Interní pull-up (20–50 kΩ). Default HIGH. Vhodné pro tlačítka (na GND). Šetří komponenty.

INPUT High-Z (plovoucí)

DDR=0, PORT=0
Bez pull-up. Vysoká impedance. Úroveň neurčitá! Pouze když ext. obvod má vlastní pull-up/down.

Příklad konfigurace (AVR C kód)
// PB5 jako OUTPUT (LED)
DDRB |= (1 << PB5); // DDR bit 5 = 1
PORTB |= (1 << PB5); // Nastav HIGH

// PD2 jako INPUT s pull-up (tlačítko)
DDRD &= ~(1 << PD2); // DDR bit 2 = 0
PORTD |= (1 << PD2); // Enable pull-up

// Čtení stavu PD2
if (PIND & (1 << PD2)) { /* HIGH */ }

07

Připojování tlačítek

Pull-up + tlačítko na GND (doporučeno)

Vcc (+5V) │ [Pull-up 10kΩ] ← interní nebo externí │ ├──── MCU Pin (INPUT s pull-up) │ [Tlačítko] │ GND

Nepřitisknuto

Pull-up drží pin na HIGH (5 V). Tlačítko otevřené → proud nemá kam téct.

Přitisknuto

Tlačítko spojí pin se zemí → pin = LOW (0 V). Proud z pull-upu teče do GND (silnější cesta).

Proč pull-up?

Bez pull-up by pin byl plovoucí → nestabilní, šum. Interní pull-up v MCU → žádné extra komponenty. Detekce: if (!(PIND & (1 << btn))) { /* pressed */ }

Varianta 2: Pull-down + tlačítko na Vcc

Nepřitisknuto = LOW, přitisknuto = HIGH. Nevýhoda: MCU typicky nemají interní pull-down → musí být externí rezistor.

08

Debouncing (odstranění zákmitů)

Problém: Button Bounce

Mechanické tlačítko při stisku/puštění několikrát zapne/vypne (zákmity) během 5–50 ms. MCU to vidí jako více stisků!

Očekávaný: ____|‾‾‾‾‾‾|____
Reálný:     ____|‾|_|‾‾|_|‾‾‾‾|____

HW Debouncing

RC filtr: kondenzátor 100 nF paralelně s tlačítkem. Zpomaluje přechody → filtruje zákmity. Přidává komponenty.

SW Debouncing (doporučeno)

Žádné extra komponenty. Simple delay (50 ms) nebo state machine. Volej v timer ISR každou 1 ms.

SW debouncing – příklady kódu
// Metoda 1: Simple delay
if (button_pressed) {
  _delay_ms(50); // Počkej 50ms
  if (button_pressed) { /* Validní stisk */ }
}

// Metoda 2: State machine (v timer ISR, volej každou 1ms)
if (button_pressed) {
  if (counter < 50) counter++;
} else { counter = 0; }
if (counter == 50 && state == 0) { state = 1; /* Validní */ }

10

Připojování LED

LED vždy s odporem! Přímé připojení = zničení!

Forward voltage (VF): Červená ~2.0 V, Zelená ~2.2 V, Modrá/Bílá ~3.3 V. Forward current (IF): typicky 20 mA.

Výpočet odporu: R = (Vcc − VF) / IF
Příklad: červená LED (2 V), Vcc=5 V, 20 mA → R = (5−2)/0.02 = 150 Ω

Active HIGH (Source)

Pin → [R] → LED → GND
Pin HIGH = svítí. MCU source current. Intuitivnější.

Active LOW (Sink)

Vcc → [R] → LED → Pin
Pin LOW = svítí. MCU sink current (často vyšší).

Řízení více LED

LED Driver IC

MAX7219, TLC5940. Constant current outputs. Komunikace přes SPI/I2C → šetří piny.

Tranzistory/MOSFETy

Pro high-power LED (>100 mA). MCU → base NPN → LED. Odděluje zatížení od MCU.

Charlieplexing

N pinů → N×(N−1) LED. 3 piny = 6 LED, 4 piny = 12 LED. Složité, ale šetří piny.

PWM Dimming

Nelze měnit jas odporem. PWM mění duty cycle → průměrná intenzita. 100% = plný jas, 50% = poloviční, 0% = zhasnuto. Frekvence min 100 Hz (ideálně 1 kHz+).

11

Displeje

7-segmentový displej

7 LED segmentů (a–g) + desetinná tečka. Zobrazuje 0–9 a některá písmena.

a = horní
b = pravý horní
c = pravý dolní
d = dolní
e = levý dolní
f = levý horní
g = středový

Common Cathode

Katody → GND. Anody na MCU přes odpory. Active HIGH (pin HIGH = segment ON).

Common Anode

Anody → Vcc. Katody na MCU přes odpory. Active LOW (pin LOW = segment ON).

Multi-digit multiplexing

4-digit = 32 LED, ale jen 12 pinů (8 segment + 4 digit select). Zobrazuj jeden digit najednou, rychle přepínej → oko vidí všechny současně. Refresh rate: 50 Hz (4 digits × 5 ms = 20 ms).

LCD a OLED

LCD 16×2 (HD44780)

4-bit mode: 6 pinů (RS, E, D4–D7). Nebo I2C backpack (PCF8574) → jen 2 piny (SDA, SCL)! Inicializace: wait 15 ms → function set → display ON → clear → entry mode.

OLED (SSD1306)

128×64 px. I2C nebo SPI. Krásný kontrast, nízká spotřeba. Knihovny: Adafruit_SSD1306, u8g2.

TFT LCD (ILI9341)

240×320 px, barevný. SPI. Touchscreen varianty. Vyšší spotřeba, více RAM.

12

Shrnutí klíčových bodů

Na zkoušku si zapamatuj

GPIO REGISTRY

  • DDR = směr (0=IN, 1=OUT). PORT = výstup/pull-up. PIN = čtení stavu (read-only)
  • OUTPUT Push-Pull: DDR=1. INPUT s pull-up: DDR=0, PORT=1. High-Z: DDR=0, PORT=0

ELEKTRICKÉ LIMITY

  • Per-pin: 20 mA (ATmega328). Per-port: 100 mA. Total MCU: 200 mA
  • Prakticky: drž se 50 % max. Překročení → zničení!

TLAČÍTKA A KLÁVESNICE

  • Pull-up + tlačítko na GND (doporučeno). Interní pull-up šetří komponenty
  • Debouncing nutný! SW: delay 50 ms nebo state machine. HW: RC filtr 100 nF
  • Matrix: N×M tlačítek = N+M pinů. Řádky=OUT, sloupce=IN (pull-up). Scanning po řádcích

LED A DISPLEJE

  • Vždy s odporem! R = (Vcc − VF) / IF. Červená ~150 Ω @ 5 V
  • Active HIGH (source) nebo Active LOW (sink). PWM pro dimming (min 100 Hz)
  • 7-segment: Common Cathode/Anode. Multi-digit = multiplexing (50 Hz refresh)
  • LCD 16×2: HD44780, 4-bit mode nebo I2C backpack (jen 2 piny!)
  • OLED SSD1306: I2C/SPI, nízká spotřeba, krásný kontrast
