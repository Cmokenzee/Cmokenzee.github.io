HDD – magnetické disky

HDD ukládá data magneticky na rotující plotny (platters). Čtecí/zápisová hlava levituje nad povrchem (~3 nm!) a mění magnetickou orientaci.

Fyzická struktura HDD
  • Platters (plotny) – hliníkové/skleněné disky s magnetickým povrchem
  • Spindle – vřeteno otáčející platters (5400–15000 RPM)
  • Read/Write heads – elektromagnety na actuator arm
  • Actuator – pohybuje hlavami radiálně
  • Controller – PCB s firmware, DRAM buffer cache
ORGANIZACE DAT NA HDD
Track = koncentrický kruh na platter (tisíce per platter)
Sector = nejmenší jednotka: tradičně 512 B, moderní 4096 B (4K native)
Cylinder = všechny tracks na STEJNÉM poloměru (bez pohybu hlavy → rychlé)

CMR vs SMR
  • CMR (Conventional) – tracks vedle sebe, rychlejší zápis
  • SMR (Shingled) – tracks překrývají, vyšší density, ale zápis POMALÝ (přepisuje sousední). Vhodné pro archiv, NE pro NAS/databáze!

SSD – Flash NAND typy

SSD ukládá data v Flash NAND paměti – elektronicky, ŽÁDNÉ pohyblivé části. Data v floating-gate tranzistorech pomocí elektrického náboje.

P/E Cycles (Program/Erase)

Počet zápisů/vymazání které cell vydrží. NAND se opotřebovává! Více bitů per cell = více stavů = citlivější = méně P/E cycles. Proto SLC nejodolnější a QLC nejméně.

Co je NVMe?

Moderní protokol navržený SPECIFICKY pro SSD (ne legacy SATA z HDD éry). Přes PCIe bus → nízká latence (~10–20 μs vs ~100 μs SATA), až 64 000 command queues!

SSD Controller a DRAM cache
  • Controller = „mozek" SSD. Řídí wear leveling, GC, ECC, encryption (Samsung Elpis, Phison E18)
  • DRAM cache = buffer pro mapping table (FTL). Zrychluje random I/O
  • DRAM-less SSD = levnější, ale pomalejší random performance
05

Wear Leveling a Garbage Collection

Wear Leveling

Problém: Flash má omezené P/E cycles. Kdyby OS psal stále na stejné bloky → předčasné selhání.

Řešení: SSD kontrolér rovnoměrně distribuuje zápisy napříč všemi bloky.

Dynamic Wear Leveling

Nová data píše do bloků s nejnižším počtem P/E cycles.

Static Wear Leveling

Periodicky přesouvá statická data (málokdy měněná) z mladých bloků do starých → uvolní mladé pro nová data.

Garbage Collection

Problém: NAND nemůže přepsat in-place!

Flash musí VYMAZAT celý BLOK (128–256 KB) před zápisem. OS chce přepsat 4 KB → SSD čte celý blok, změní 4 KB, vymaže, zapíše zpět. Write amplification!

Garbage Collection proces
1
SSD označí staré stránky jako INVALID
2
Blok obsahuje mix platných + invalidních stránek
3
GC: přesun platných stránek do jiného bloku
4
Vymazání celého bloku (nyní prázdný)
5
Blok připraven pro nová data
TRIM command

OS říká SSD které bloky jsou smazané (soubor deleted) → SSD může okamžitě označit jako invalid. Windows/Linux/macOS podporují TRIM. Udržuje výkon SSD dlouhodobě!

Flash paměti – NOR vs NAND

Flash = non-volatilní paměť založená na floating-gate tranzistorech. Elektricky programovatelná a mazatelná. Mazání po BLOCÍCH (ne bytech) → rychlejší, vyšší density než EEPROM.

VlastnostNOR FlashNAND Flash
PřístupRandom (byte-level čtení)Block/page (sekvenční)
ČteníRychléRychlé
ZápisPomalýRychlejší
XIPANO (Execute-in-Place)NE (kopie do RAM)
DensityNižšíVyšší
CenaDražšíLevnější
PoužitíBIOS/UEFI, bootloadersSSD, SD, USB disky
XIP (Execute-in-Place)

NOR Flash umožňuje CPU spouštět kód přímo z paměti bez kopírování do RAM. Proto se používá pro BIOS/firmware. NAND toto neumí.

Flash – operace a struktura

NAND Flash hierarchie

Cell → Page → Block → Plane → Die → Package
Page (4–16 KB) = READ/WRITE jednotka │ Block (128–256 KB) = ERASE jednotka

Flash operace

OperaceRychlostGranularitaPoznámka
READ~25–100 μsPageRychlé
PROGRAM (Write)~200–1000 μsPageJen 1→0 (ne opačně!)
ERASE~1–5 msBlockPOMALÉ! Nastaví vše na 1
Proč nelze přepsat in-place

Flash může měnit jen 1→0 (program). Pro 0→1 nutný ERASE celého bloku!

→ Proto je nutný wear leveling, garbage collection a TRIM.

Flash – ECC, retention, 3D NAND

Error Correction (ECC)

Flash NAND má error rate – bit flips, read disturb, retention loss. Zejména u TLC/QLC (více stavů = citlivější).

AlgoritmusSílaPoužití
Hamming CodeOpraví 1-bit errorStarší SSD
BCHMulti-bit korekceBěžné v SSD
LDPCSilnější, moderníTLC/QLC SSD

ECC overhead: 7–15% kapacity. SSD firmware transparentně opravuje chyby.

Data Retention

Elektrony v floating-gate postupně unikají (tunelování). Data zmizí po letech bez napájení.

Typ NANDRetention
SLC10+ let
MLC5–10 let
TLC3–5 let
QLC1–3 roky

Pro dlouhodobý archiv (>10 let) → lepší HDD nebo pásky!

3D NAND (V-NAND)

Vertikální stacking

Problém 2D NAND: density limit – cells interferují, reliability klesá.

Řešení: NAND cells stackovány VERTIKÁLNĚ – až 200+ vrstev!

  • Vyšší density bez zmenšování cell size
  • Lepší reliability, nižší interference
  • Samsung V-NAND, Micron 3D NAND

Současný standard – všechny moderní SSD používají 3D NAND.

11

Shrnutí klíčových bodů

Na zkoušku si zapamatuj

HDD (MAGNETICKÉ)

  • Rotující platters, čtecí hlavy. Organizace: track → sector (4K) → cylinder
  • RPM: 5400 (laptop), 7200 (desktop), 15000 (enterprise)
  • Latence: seek ~8 ms + rotational ~4 ms = ~12–15 ms total
  • Sequential: 100–200 MB/s, Random: 0.5–2 MB/s (velmi pomalé!)
  • Kapacita: až 20 TB, levné ($0.015/GB). CMR (rychlé) vs SMR (pomalý zápis)

SSD (FLASH NAND)

  • NAND typy: SLC (100k P/E), MLC (10k), TLC (3k, mainstream), QLC (1k, budget)
  • Form: 2.5" SATA (~550 MB/s), M.2 NVMe PCIe 4.0 (~7 GB/s!), PCIe 5.0 (~14 GB/s)
  • Latence: 10–100 μs (100× rychlejší než HDD)
  • Wear leveling: dynamic (nejmladší blok) + static (přesun starých dat)
  • Garbage collection: přesun valid stránek, erase bloků. TRIM = OS info o deleted

SD KARTY

  • Formáty: SD (32×24mm), microSD (15×11mm, nejběžnější)
  • Kapacita: SDHC (4–32 GB), SDXC (64 GB–2 TB), SDUC (2–128 TB)
  • Speed: C10 (10 MB/s), U3/V30 (30 MB/s), V90 (90 MB/s), A2 (4000 IOPS)
  • Rozhraní: UHS-I (104 MB/s), UHS-II (312 MB/s), SD Express PCIe (~2 GB/s!)
  • SPI mode pro embedded (Arduino, ESP32) – 4 vodiče, jednoduchý

FLASH PAMĚTI

  • NOR: random access, XIP (execute-in-place), BIOS/firmware
  • NAND: block access, vysoká density, SSD/SD/USB
  • Struktura: Page (4–16 KB, read/write) → Block (128–256 KB, erase)
  • Nelze přepsat in-place: 1→0 OK, 0→1 = ERASE celého bloku!
  • ECC: BCH/LDPC, 7–15% overhead. Retention: SLC 10+ let, QLC 1–3 roky
  • 3D NAND: vertikální stacking 200+ vrstev = standard moderních SSD
Zlatá pravidla
  • HDD = velká kapacita, levné, ale pomalé (12–15 ms). Pro archiv a bulk storage
  • SSD NVMe PCIe 4.0 = 7 GB/s! Pro OS, gaming, profesionální práci
  • Flash NAND erase po blocích (ne in-place!) → wear leveling + GC nutné
  • TLC = mainstream (3k P/E), QLC = budget (1k P/E). 3D NAND = standard
  • SD Express PCIe = budoucnost karet (~2 GB/s). SPI mode pro embedded
